CSS-এ টেক্সটের বিভিন্ন অংশের (অক্ষর, শব্দ, লাইন ইত্যাদি) ফাঁকা জায়গা বা স্পেস নিয়ন্ত্রণ করার জন্য বেশ কিছু Text Spacing Properties রয়েছে। এটি ওয়েবসাইটের কন্টেন্ট পড়ার অভিজ্ঞতা (Readability) বাড়াতে সাহায্য করে।

মূল টেক্সট স্পেসিং প্রোপার্টিগুলো নিচে তুলে ধরা হলো:

১. Letter Spacing (letter-spacing)
টেক্সটের প্রতিটি অক্ষরের (Letter) মধ্যবর্তী দূরত্ব বাড়ানো বা কমানোর জন্য ব্যবহার করা হয়।

ব্যবহার: letter-spacing: 2px; (স্পেস বাড়াতে) অথবা letter-spacing: -1px; (স্পেস কমাতে)।

কখন লাগবে: শিরোনাম বা Heading-কে আরও আকর্ষণীয় বা স্পষ্ট করতে এটি বেশি ব্যবহৃত হয়।

২. Word Spacing (word-spacing)
দুটি শব্দের (Word) মধ্যবর্তী ফাঁকা জায়গা নিয়ন্ত্রণ করতে এটি ব্যবহৃত হয়।

ব্যবহার: word-spacing: 10px;

কখন লাগবে: টেক্সট ডিজাইন বা জাস্টিফাইড প্যারাগ্রাফে শব্দের দূরত্ব ঠিক করার জন্য।

৩. Line Height (line-height)
টেক্সটের একটি লাইন থেকে অন্য লাইনের উল্লম্ব (Vertical) দূরত্ব বা লাইনের উচ্চতা নির্ধারণ করে।

ব্যবহার: line-height: 1.6; (সাধারণত অনুপাত হিসেবে দেওয়া ভালো) অথবা line-height: 24px;

কখন লাগবে: প্যারাগ্রাফ পড়ার সহজগম্যতা বাড়াতে। স্ট্যান্ডার্ড ওয়েবে 1.5 থেকে 1.6 লাইন-হাইট বেশি ব্যবহৃত হয়।

৪. Text Indent (text-indent)
কোনো প্যারাগ্রাফ বা ব্লক এলিমেন্টের প্রথম লাইনের শুরুতে কতটুকু খালি জায়গা থাকবে তা নির্ধারণ করে।

ব্যবহার: text-indent: 30px;

কখন লাগবে: বই বা ব্লগের স্টাইলে প্যারাগ্রাফের প্রথম লাইন একটু ভেতরের দিকে সরাতে।

৫. White Space (white-space)
এলিমেন্টের ভেতরের এক্সট্রা স্পেস এবং লাইন ব্রেক কীভাবে প্রসেস হবে তা নিয়ন্ত্রণ করে।

ব্যবহার: white-space: nowrap; (টেক্সট নিচে না নেমে এক লাইনে থাকবে), white-space: pre; (কোডে যেভাবে স্পেস দেওয়া আছে হুবহু সেভাবে দেখাবে)।

উদাহরণ কোড Snippet:

CSS
p {
  letter-spacing: 0.5px;
  word-spacing: 2px;
  line-height: 1.6;
  text-indent: 20px;
}
