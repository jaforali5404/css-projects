CSS Transformation (ট্রান্সফরমেশন) হলো একটি শক্তিশালী ফিচারের মাধ্যমে কোনো লেআউট পরিবর্তন না করেই ওয়েবসাইটের কোনো এলিমেন্টের আকার, আকৃতি, অবস্থান বা দিক পরিবর্তন করার পদ্ধতি।

CSS Transform-এর মূল ধরণ:

১. 2D Transforms (দ্বিমাত্রিক)

translate(x, y): এলিমেন্টকে তার বর্তমান স্থান থেকে ডানে-বামে (X-অক্ষ) বা উপরে-নিচে (Y-অক্ষ) সরিয়ে নেয়।

scale(x, y): এলিমেন্টের আকার বড় বা ছোট করে (যেমন: scale(1.5) দিলে ৫০% বড় হবে)।

rotate(angle): এলিমেন্টকে নির্দিষ্ট ডিগ্রিতে ঘোরায় (যেমন: rotate(45deg))।

skew(x-angle, y-angle): এলিমেন্টকে একপাশে বাকিয়ে দেয় বা তির্যক করে।

২. 3D Transforms (ত্রিমাত্রিক)

rotateX(), rotateY(), rotateZ(): X, Y বা Z অক্ষ বরাবর এলিমেন্টকে ৩D ব্যাকগ্রাউন্ডে ঘোরানো যায়।

translate3d() ও scale3d(): ত্রিমাত্রিক স্পেসে এলিমেন্টকে সরানো বা বড়-ছোট করার জন্য ব্যবহৃত হয়।

সাধারণ ব্যবহারের উদাহরণ:

CSS
.card {
  /* এলিমেন্টকে ৪৫ ডিগ্রি ঘোরানো এবং ১০% বড় করা */
  transform: rotate(45deg) scale(1.1);
  
  /* পরিবর্তনটি মসৃণ করার জন্য transition যোগ করা হয় */
  transition: transform 0.3s ease;
}

.card:hover {
  /* মাউস নিলে উপরে ১০ পিক্সেল উঠে যাবে */
  transform: translateY(-10px);
}
প্রধান সুবিধা:

পারফর্মেন্স: margin বা top/left পরিবর্তন করার চেয়ে transform ব্যবহার করা ব্রাউজারের জন্য অনেক দ্রুত, কারণ এটি GPU (Graphics Processing Unit) ব্যবহার করে রেন্ডার হয়।

এনিমেশন: CSS transition বা @keyframes-এর সাথে মিলিয়ে দারুণ ইন্টারঅ্যাক্টিভ এনিমেশন তৈরি করা যায়।
