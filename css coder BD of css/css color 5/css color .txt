Choice A
CSS-এ ওয়েবসাইট সুন্দর করার জন্য মূলত ৪টি সহজ উপায়ে কালার বা রং ব্যবহার করা হয়:

রঙের নাম (Color Names): সরাসরি রঙের নাম লেখা হয়।

উদাহরণ: red, blue, green

হেক্স কোড (HEX Code): # চিহ্নের পর ৬ অক্ষরের কোড বসানো হয়। এটি সবচেয়ে বেশি ব্যবহৃত হয়।

উদাহরণ: #ff0000 (লাল), #0000ff (নীল)

RGB (Red, Green, Blue): লাল, সবুজ ও নীলের মিশ্রণ (মান ০ থেকে ২৫৫)।

উদাহরণ: rgb(255, 0, 0) (লাল)

RGBA: RGB-এর মতো, তবে শেষের মানটি দিয়ে স্বচ্ছতা (Opacity) কমানো বা বাড়ানো যায় (মান ০.০ থেকে ১.০)।

উদাহরণ: rgba(255, 0, 0, 0.5) (অর্ধেক স্বচ্ছ লাল)

ছোট উদাহরণ
CSS
p {
  color: blue; /* টেক্সটের রং নীল হবে */
  background-color: #ffff00; /* ব্যাকগ্রাউন্ড হলুদ হবে */
}



*******



CSS-এ কোনো লেখার বা ব্যাকগ্রাউন্ডের রঙ নির্ধারণ করতে মূলত ৪টি সহজ পদ্ধতি সবচেয়ে বেশি ব্যবহার করা হয়:

১. কালারের সরাসরি নাম (Color Names)
সহজ রঙের জন্য সরাসরি ইংরেজিতে নাম লিখে দেওয়া যায় (যেমন: red, blue, green, black ইত্যাদি)।

CSS
p {
  color: red;
}
২. হেক্স কোড (HEX Code)
এটি # দিয়ে শুরু হয় এবং ৬টি সংখ্যা বা অক্ষরের একটি কোড থাকে (যেমন: #FF0000 মানে লাল, #000000 মানে কালো, #FFFFFF মানে সাদা)।

CSS
p {
  color: #ff5733;
}
৩. RGB ও RGBA
এটি লাল (Red), সবুজ (Green) ও নীল (Blue)-এর মিশ্রণ দিয়ে রঙ তৈরি করে। এর মান 0 থেকে 255 পর্যন্ত হয়।

RGBA-তে অতিরিক্ত A (Alpha) দিয়ে রঙের স্বচ্ছতা বা ট্রান্সপারেন্সি (০ থেকে ১) নিয়ন্ত্রণ করা যায়।

CSS
p {
  color: rgb(255, 0, 0);       /* লাল */
  color: rgba(255, 0, 0, 0.5);  /* ৫০% স্বচ্ছ লাল */
}
৪. HSL ও HSLA
এটি হিউ (Hue - রঙের শেড), স্যাচুরেশন (Saturation - রঙের ঘনত্ব) এবং লাইটনেস (Lightness - উজ্জ্বলতা) দিয়ে কাজ করে।

CSS
p {
  color: hsl(0, 100%, 50%);
}
সাধারণত কাজের ক্ষেত্রে HEX এবং ট্রান্সপারেন্ট বা হালকা রঙের জন্য RGBA সবচেয়ে বেশি ব্যবহৃত হয়।

হ্যাঁ, উপরে যেগুলো বলা হয়েছে সেগুলো ছাড়াও CSS-এ কালার দেওয়ার আরও কিছু আধুনিক ও জনপ্রিয় পদ্ধতি আছে। এগুলোও খুব সহজ, সংক্ষেপে দেখে নিন:
১. HSL এবং HSLA (সবচেয়ে সহজভাবে রঙ বদলানোর উপায়)মানুষের বোঝার জন্য HSL পদ্ধতিটি খুব সহজ
।H (Hue): রঙের চাকা বা Degree (০ থেকে ৩৬০)। যেমন: 0 = লাল, 120 = সবুজ, 240 = নীল।
S (Saturation): রঙের গাঢ়ত্ব (০% থেকে ১০০%)।L (Lightness): আলো বা উজ্জ্বলতা (০% মানে কালো, ১০০% মানে সাদা)
।HSLA: শেষের A দিয়ে স্বচ্ছতা (Opacity) নির্ধারণ করা হয়।উদাহরণ: hsl(0, 100%, 50%) (একদম খাঁটি লাল)
২. Color Gradients (একাধিক রঙের মিশ্রণ)শুধু একটি রঙ না দিয়ে যখন দুই বা ততধিক রঙের সুন্দর মিশ্রণ (Shade/Gradient) তৈরি করতে চান, তখন এটি ব্যবহার করা হয়।
Linear Gradient: একদিক থেকে অন্যদিকে রঙ যায় (যেমন: বাম থেকে ডানে)।Radial Gradient: মাঝখান থেকে গোল হয়ে বাইরে ছড়ায়।
উদাহরণ: background: linear-gradient(to right, red, yellow);
৩. CSS Variables (রঙের নাম বানিয়ে রাখা)একই রঙ বারবার ব্যবহার না করে একটি জায়গায় নাম দিয়ে বানিয়ে রাখা যায়,
 যাতে পরে এক ক্লিকেই পুরো ওয়েবসাইটের থিম বদলে ফেলা যায় (যেমন: Dark Mode)।উদাহরণ:CSS:root {
  --primary-color: #3498db; /* মূল রঙের কোড রাখলাম */
}

h1 {
  color: var(--primary-color); /* প্রয়োজনমতো ব্যবহার করলাম */
}
৪. currentColor Keywords (প্যারেন্ট এলিমেন্টের রঙ নেওয়া)এটি ব্যবহারে লেখার যে কালার থাকবে, বর্ডার বা অন্য কিছুর কালার আপনাতেই সেটি পেয়ে যাবে।
