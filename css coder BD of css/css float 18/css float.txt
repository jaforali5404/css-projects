CSS-এ "CSS Float" (বা Float property) মূলত কোনো এলিমেন্টকে (যেমন: ছবি বা বক্স) তার আশেপাশের কন্টেন্ট বা টেক্সটের বামে (Left) বা ডানে (Right) ভাসিয়ে বা সরিয়ে রাখার জন্য ব্যবহার করা হয়।

এর মাধ্যমে টেক্সটকে ছবির চারপাশে জড়িয়ে (Wrap) সুন্দর লেআউট তৈরি করা যায়, ঠিক যেমনটা সংবাদপত্র বা ম্যাগাজিনে দেখা যায়।

CSS Float-এর প্রধান Value সমূহ

float: left; — এলিমেন্টটি তার পাত্রের (Container) বাম দিকে সরে যাবে এবং টেক্সট/অন্য এলিমেন্ট তার ডান দিক দিয়ে প্রবাহিত হবে।

float: right; — এলিমেন্টটি ডান দিকে সরে যাবে এবং টেক্সট তার বাম দিক দিয়ে প্রবাহিত হবে।

float: none; — এটি ডিফল্ট মান। এলিমেন্টটি সাধারণ ফ্লোতেই থাকবে (কোনো ভাসমান প্রভাব থাকবে না)।

float: inherit; — তার অভিভাবক (Parent) এলিমেন্টের float মানটি গ্রহণ করবে।

Float ব্যবহারের সহজ উদাহরণ

CSS
img {
  float: left;
  margin-right: 15px;
}
এই কোডটি লেখার ফলে ছবিটি বামে চলে যাবে এবং ডানপাশে ১৫ পিক্সেল জায়গা খালি রেখে টেক্সট তার চারপাশ দিয়ে বয়ে যাবে।

Clear Property এবং Clearfix Problem

Float ব্যবহার করলে অনেক সময় Parent এলিমেন্টের হাইট (Height) শূন্য হয়ে যায়, যাকে "Float Collapsing" বলা হয়। এর সমাধানের জন্য clear প্রপার্টি বা clearfix ব্যবহার করা হয়।

CSS
/* Float-এর প্রভাব বন্ধ করতে */
.clear-div {
  clear: both; /* left, right বা both ব্যবহার করা যায় */
}
বর্তমান অবস্থা (Modern Web Design)

অতীতে পুরো ওয়েবসাইটের লেআউট (যেমন: সাইডবার, গ্রিড) তৈরি করতে Float প্রচুর ব্যবহার করা হতো। তবে বর্তমানে আধুনিক ওয়েব ডিজাইনে ওয়েবসাইট লেআউট তৈরির জন্য CSS Flexbox এবং CSS Grid ব্যবহার করা হয়, কারণ এগুলো ব্যবহার করা অনেক সহজ এবং বেশি ফ্লেক্সিবল।

এখন মূলত শুধু কোনো টেক্সটের পাশে ইমেজ ভাসিয়ে রাখার মতো ছোটখাটো কাজের জন্যই Float ব্যবহার করা হয়।
