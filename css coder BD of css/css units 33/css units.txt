১. Absolute Length Units (নির্দিষ্ট মাপ)ইউনিটনামআসল মাপ / সমতুল্য মান
px Pixels$1\text{px} = \frac{1}{96}\text{in}$ (ডিজিটাল স্ক্রিনের মূল মাপ)
pt Points$1\text{pt} = \frac{1}{72}\text{in}$ ($1.33\text{px}$)
pc Picas$1\text{pc} = 12\text{pt} = 16\text{px}$
in Inches$1\text{in} = 96\text{px} = 2.54\text{cm}$
cm Centimeters$1\text{cm} = 37.8\text{px} = 10\text{mm}$
mm Millimeters$1\text{mm} = 3.78\text{px} = 0.1\text{cm}$
Q Quarter-mm$1\text{Q} = \frac{1}{4}\text{mm} = 0.945\text{px}$
 ২. Relative Length Units (আপেক্ষিক মাপ)ইউনিটনামকিসের ওপর ভিত্তি করে মাপা হয়?
em Font size of parentপ্যারেন্ট এলিমেন্টের ফন্ট সাইজ ($16\text{px}$ ডিফোল্ট হলে $1\text{em} = 16\text{px}$)
rem Root font sizeরুট বা <html>-এর ফন্ট সাইজ ($1\text{rem} = 16\text{px}$)
ex x-heightব্যবহার করা ফন্টের ছোট হাতের 'x' অক্ষরের উচ্চতা 
ch Zero widthব্যবহার করা ফন্টের '0' (শূন্য) অক্ষরের প্রস্থ
cap Cap heightব্যবহার করা ফন্টের বড় হাতের (Capital) অক্ষরের উচ্চতা
ic Ideographic countসিজেেকে (চীনা/জাপানি) অক্ষরের সাইজ 
lh Line heightবর্তমান এলিমেন্টের line-height-এর সমান
rlh Root line heightরুট এলিমেন্টের (<html>) line-height-এর সমান
৩. Viewport Units (স্ক্রিনের মাপ)ইউনিটনামআসল মাপ
vw Viewport Widthব্রাউজার স্ক্রিনের মোট প্রস্থের $1\%$ ($100\text{vw} =$ পুরো স্ক্রিন) 
vh Viewport Heightব্রাউজার স্ক্রিনের মোট উচ্চতার $1\%$ ($100\text{vh} =$ পুরো স্ক্রিন)
vmin Viewport Minimumvw এবং vh-এর মধ্যে যেটি ছোট, তার $1\%$vmaxViewport Maximumvw এবং vh-এর মধ্যে যেটি বড়, তার $1\%$
svh / svw Small Viewportমোবাইল ব্রাউজারের অ্যাড্রেস বার দৃশ্যমান থাকা অবস্থার $1\%$
lvh / lvw Large Viewportমোবাইল ব্রাউজারের অ্যাড্রেস বার লুকিয়ে যাওয়ার পর স্ক্রিনের $1\%$
dvh / dvw Dynamic Viewportমোবাইল স্ক্রিনের কারেন্ট অবস্থা অনুযায়ী স্বয়ংক্রিয় পরিবর্তিত $1\%$
৪. Angle Units (কোণের মাপ)ইউনিটনামসমতুল্য মান
deg Degrees$0\text{deg}$ থেকে $360\text{deg}$ (এক পুরো বৃত্ত)
grad Gradians$1\text{turn} = 400\text{grad}$ ($100\text{grad} = 90\text{deg}$)
rad Radians$1\text{turn} = 2\pi\text{rad} \approx 6.28\text{rad}$
turn Turns$1\text{turn} = 360\text{deg}$ ($0.5\text{turn} = 180\text{deg}$)
৫. Time Units (সময়)ইউনিটনামসমতুল্য মান
s Seconds১ সেকেন্ড
ms Milliseconds$1\text{s} = 1000\text{ms}$ ($0.5\text{s} = 500\text{ms}$)
৬. Resolution Units (রেজোলিউশন)ইউনিটনামসমতুল্য মান
dpi Dots per inchপ্রতি ইঞ্চিতে ডটের সংখ্যা
dpcm Dots per cm$1\text{dpcm} \approx 2.54\text{dpi}$
dppx / xDots per px$1\text{dppx} = 96\text{dpi}$ (সাধারণ স্ক্রিনে $1\text{dppx}$, রেটিনা ডিসপ্লেতে $2\text{x}$)
