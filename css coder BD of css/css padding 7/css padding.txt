CSS-এ Padding (প্যাডিং) হলো কোনো এলিমেন্টের (যেমন: একটি বাটন,
 টেক্সট বক্স বা কার্ড) কন্টেন্ট এবং তার বর্ডার (Border)-এর ভেতরের মধ্যবর্তী খালি জায়গা বা স্পেস।সোজা কথায়,
 কন্টেন্টকে যেন বর্ডারের গায়ে ঘেঁষে না থাকে, বরং কিছুটা শ্বাস নেওয়ার জায়গা পায়—সেজন্যই প্যাডিং ব্যবহার করা হয়।
প্যাডিং কীভাবে কাজ করে?
আপনি ৪টি ভিন্ন ভিন্ন দিকে আলাদা করে প্যাডিং দিতে পারেন:padding-top: 
উপরের স্পেসpadding-right:
 ডানপাশের স্পেসpadding-bottom:
 নিচের স্পেসpadding-left:
 বামপাশের স্পেসউদাহরণ:
CSSdiv {
  padding-top: 20px;
  padding-right: 15px;
  padding-bottom: 20px;
  padding-left: 15px;
}
প্যাডিং লেখার শর্টকাট নিয়ম (Shorthand)আলাদা করে ৪ দিক না লিখে,
 এক লাইনেও প্যাডিং লেখা যায়:লেখার স্টাইলকাজের ধরনউদাহরণ৪টি মান (4 Values)ঘড়ির কাঁটার মতো কাজ করে: 
উপরে, ডানে, নিচে, বামেpadding: 10px 20px 15px 5px;
৩টি মান (3 Values)উপরে, ডানে-বামে (একসাথে), নিচেpadding: 10px 20px 15px;
২টি মান (2 Values)উপরে-নিচে (একসাথে), ডানে-বামে (একসাথে)padding: 20px 15px;
১টি মান (1 Value)৪ দিকেই সমান স্পেস দেবেpadding: 20px;একটি বিষয় মাথায় রাখা ভালো:
 Box-Sizingডিফল্টভাবে, আপনি কোনো এলিমেন্টে প্যাডিং যোগ করলে সেটির মোট সাইজ (Width & Height) বড় হয়ে যায়।
যেমন: আপনার ডিভ (Div)-এর width: 100px এবং আপনি padding: 20px দিলেন। 
এতে ডিভটির মোট প্রস্থ হয়ে যাবে $100 + 20 + 20 = 140\text{px}$।টিপস: 
এলিমেন্টের মোট সাইজ ঠিক রাখতে CSS-এর শুরুতে সবসময় এটি ব্যবহার করা ভালো:
CSS* {
  box-sizing: border-box;
}
