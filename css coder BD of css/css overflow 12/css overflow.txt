CSS-এ Overflow প্রপার্টি মূলত নিয়ন্ত্রণ করে যখন কোনো এলিমেন্টের কন্টেন্ট (লেখা বা ছবি) তার বরাদ্দকৃত বক্স বা সাইজের (Width ও Height) চেয়ে বড় হয়ে যায়, তখন বাড়তি কন্টেন্টটি কীভাবে দেখানো হবে।

ডিফল্টভাবে কন্টেন্ট বক্সের বাইরে চলে গেলে তা উপচে বা ওভারফ্লো হয়ে বাইরে দেখা যায়। এই আচরণ পরিবর্তনের জন্য overflow প্রপার্টি ব্যবহার করা হয়।

মূল Values ও তাদের কাজ

visible: এটি ডিফল্ট ভ্যালু। বাড়তি কন্টেন্টটি কন্টেইনারের সীমানা পেরিয়ে বাইরে দেখা যাবে, কোনো স্ক্রলবার আসবে না।

hidden: বক্সের নির্দিষ্ট সাইজের বাইরের বাড়তি কন্টেন্ট পুরোপুরি লুকিয়ে ফেলা হয়। বাড়তি অংশ আর দেখা যায় না।

scroll: কন্টেন্ট বড় হোক বা ছোট, কন্টেইনারে সবসময় স্ক্রলবার (Horizontal & Vertical) যুক্ত থাকবে।

auto: কন্টেন্ট যদি সাইজের চেয়ে বড় হয়, কেবল তখনই প্রয়োজন অনুযায়ী স্ক্রলবার দেখাবে। সাধারণত এটিই বেশি ব্যবহৃত হয়।

নির্দিষ্ট Direction অনুযায়ী Overflow

আপনি চাইলে ডানে-বামে (X-axis) বা উপরে-নিচে (Y-axis) আলাদাভাবে ওভারফ্লো নিয়ন্ত্রণ করতে পারেন:

CSS
div {
  overflow-x: hidden; /* ডানে-বামে ওভারফ্লো লুকাতে */
  overflow-y: scroll; /* উপরে-নিচে স্ক্রলবার আনতে */
}
সাধারণ ব্যবহারের উদাহরণ

CSS
.card-box {
  width: 300px;
  height: 200px;
  overflow: auto; /* কন্টেন্ট বেশি হলে নিজে থেকেই স্ক্রলবার আসবে */
}
কখন কোনটি ব্যবহার করবেন?

Drop-down Menu বা Tooltip: visible ব্যবহার করা ভালো, যাতে মেনুটি বক্সের বাইরে বের হতে পারে।

Image Gallery বা Layout truncation: বাড়তি অংশ কেটে ফেলার জন্য hidden ব্যবহার করা হয়।

긴 Text বা Mobile Card View: লেখা বেশি থাকলে লেআউট ঠিক রেখে স্ক্রল করার সুবিধা দিতে auto ব্যবহার করা সেরা উপায়।
