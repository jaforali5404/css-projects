CSS-এ text-align প্রপার্টি ব্যবহার করে কোনো ব্লকের (যেমন: <div>, <p>, <h1>) ভিতরের টেক্সট বা ইনলাইন এলিমেন্টকে আনুভূমিকভাবে (Horizontally) সাজানো বা এলাইন করা হয়।

মূল ভ্যালুসমূহ

left: টেক্সটকে বাম দিকে সাজায়। (ডিফল্ট আচরণ)

right: টেক্সটকে ডান দিকে সাজায়।

center: টেক্সটকে মাঝখানে নিয়ে আসে।

justify: প্রতিটি লাইনের ডান এবং বাম পাশ সমান করার জন্য শব্দগুলোর মাঝের স্পেস বা ফাঁকা জায়গা বাড়িয়ে দেয় (পত্রিকা বা বইয়ের মতো)।

ব্যবহারের নিয়ম

CSS
p {
  text-align: center;
}
জরুরি কিছু টিপস

text-align শুধু ইনলাইন (Inline) বা ইনলাইন-ব্লক (Inline-block) এলিমেন্টের (যেমন: টেক্সট, <span>, <a>, <img>) ওপর কাজ করে।

পুরো কোনো ব্লক এলিমেন্টকে (যেমন একটি <div>) পেজের মাঝে আনতে text-align: center ব্যবহার না করে margin: 0 auto; অথবা Flexbox ব্যবহার করা ভালো।



******



CSS-এ text-align প্রপার্টি ব্যবহার করা হয় কোনো এলিমেন্টের (যেমন: <p>, <h1>, <div>) ভেতরে থাকা টেক্সট বা ইনলাইন কন্টেন্টকে অনুভূমিকভাবে (horizontally) সাজানোর জন্য।

প্রধান Value বা মানসমূহ

text-align: left;

টেক্সটকে বাম দিকে সাজায়। এটি ডিফল্ট বা স্বভাবজাত নিয়ম (ইংরেজি বা বাংলা ভাষার ক্ষেত্রে)।

text-align: right;

টেক্সটকে ডান দিকে সাজায়। সাধারণত আরবি বা হিব্রু ভাষার টেক্সট এবং সংখ্যার ক্ষেত্রে বেশি ব্যবহৃত হয়।

text-align: center;

টেক্সটকে মাঝখানে (Center) নিয়ে আসে। হেডিং বা শিরোনাম সাজাতে এটি সবচেয়ে বেশি ব্যবহৃত হয়।

text-align: justify;

টেক্সটের প্রতিটি লাইনকে বাম এবং ডান—উভয় পাশেই সমানভাবে ছড়িয়ে দেয় (যেমনটা পত্রিকা বা বইয়ের পাতায় দেখা যায়)।

জরুরি কিছু বিষয়

মনে রাখবেন: text-align শুধুমাত্র Block-level element (যেমন: <div>, <p>, <h1>) এর ওপর কাজ করে। এটি সরাসরি কোনো <span> বা <a> ট্যাগে প্রয়োগ করলে কাজ করবে না, কারণ এরা Inline element। ইনলাইন এলিমেন্টকে অ্যালাইন করতে হলে তার প্যারেন্ট (Parent) ব্লক এলিমেন্টে text-align দিতে হয়।

ব্যবহারের উদাহরণ

CSS
/* শিরোনাম মাঝখানে নেওয়ার জন্য */
h1 {
  text-align: center;
}

/* প্যারাগ্রাফের দুই পাশ সমান করার জন্য */
p {
  text-align: justify;
}
আপনার কি নির্দিষ্ট কোনো ডিজাইন বা প্রোজেক্টের জন্য text-align ব্যবহারে সমস্যা হচ্ছে?
