========css text decoration=======
CSS-এ text-decoration প্রপার্টি ব্যবহার করা হয় টেক্সটের নিচে, ওপরে বা মাঝখানে দাগ (Line) দেওয়ার জন্য এবং টেক্সটের স্টাইল ফরম্যাট করার জন্য। সাধারণত লিংকের ডিফল্ট আন্ডারলাইন সরাতে বা কোনো লেখার ওপর দাগ দিয়ে কাটতে (Strikethrough) এটি সবচেয়ে বেশি ব্যবহৃত হয়।

মূল উপাদানসমূহ (Shorthand Property)

text-decoration আসলে কয়েকটি প্রপার্টির একটি সংক্ষিপ্ত রূপ (Shorthand):

text-decoration-line (কোথায় দাগ হবে)

none: কোনো দাগ থাকবে না (লিংকের আন্ডারলাইন সরাতে ব্যবহৃত হয়)।

underline: লেখার নিচে দাগ দেবে।

line-through: লেখার মাঝখান দিয়ে দাগ দেবে (যেমন: ডিসকাউন্ট বা কাটা দাম দেখাতে)।

overline: লেখার ওপরে দাগ দেবে।

text-decoration-color (দাগের রঙ)

দাগের রঙ পরিবর্তন করতে ব্যবহৃত হয় (যেমন: red, #ff0000)।

text-decoration-style (দাগটি কেমন দেখাবে)

solid: সাধারণ সোজা দাগ (ডিফল্ট)।

dashed: ড্যাশ বা কাটা কাটা দাগ (---)।

dotted: ডট ডট বা ফোঁটা দাগ (...)।

wavy: ঢেউ খেলানো দাগ (~~~)।

ব্যবহারের উদাহরণ

CSS
/* ১. লিংকের আন্ডারলাইন মুছে ফেলা */
a {
  text-decoration: none;
}
/* ২. লেখার নিচে লাল রঙের ঢেউ খেলানো দাগ */
h2 {
  text-decoration: underline red wavy;
}

/* ৩. কাটা দাম (Discounted Price) দেখানো */
.old-price {
  text-decoration: line-through grey;
}
