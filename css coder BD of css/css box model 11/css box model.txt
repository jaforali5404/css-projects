CSS Box Model হলো HTML এলিমেন্টের চারপাশের স্থান, বর্ডার এবং প্যাডিং নির্ধারণ করার একটি মৌলিক ধারণা। প্রতিটি HTML এলিমেন্টকে একটি চারকোনা বাক্সের মতো মনে করা হয়, যা চারটি প্রধান অংশ নিয়ে গঠিত:

Content: মূল অংশ যেখানে টেক্সট, ছবি বা অন্যান্য কন্টেন্ট থাকে। এর নির্দিষ্ট width এবং height থাকে।

Padding: কন্টেন্ট এবং বর্ডারের মধ্যকার খালি জায়গা। এটি কন্টেন্টকে বর্ডারের সাথে লেগে থাকা থেকে বাঁচায় এবং ব্যাকগ্রাউন্ড কালার প্যাডিং পর্যন্ত দেখা যায়।

Border: প্যাডিং এবং কন্টেন্টকে ঘিরে থাকা সীমানা বা বর্ডার।

Margin: বর্ডারের বাইরের খালি জায়গা, যা অন্য কোনো এলিমেন্ট থেকে এই বাক্সটিকে নির্দিষ্ট দূরত্বে সরিয়ে রাখে। এটি সম্পূর্ণ স্বচ্ছ।

বক্স মডেল সংক্রান্ত গুরুত্বপূর্ণ প্রপার্টি

ডিফল্টভাবে CSS-এ লেআউট তৈরির সময় box-sizing: content-box; কাজ করে, যা পুরো বক্সের সাইজ বাড়িয়ে দিতে পারে। তাই কাজের সুবিধার্থে box-sizing: border-box; ব্যবহার করা হয়।

content-box (Default): এলিমেন্টের মোট চওড়া = width + padding + border

border-box (Recommended): এলিমেন্টের মোট চওড়া সেট করা width-এর সমানই থাকে। প্যাডিং এবং বর্ডার সেই width-এর ভেতরেই অ্যাডজাস্ট হয়ে যায়।



*******



HTML
<!DOCTYPE html>
<html lang="bn">
<head>
  <meta charset="UTF-8">
  <style>
    .card {
      /* 1. Content: মূল কন্টেন্টের আকার */
      width: 300px;
      height: 100px;
      background-color: #f0f0f0;

      /* 2. Padding: কন্টেন্ট ও বর্ডারের ভেতরের দূরত্ব */
      padding: 20px;

      /* 3. Border: চারপাশের বর্ডার */
      border: 5px solid #007bff;

      /* 4. Margin: অন্য এলিমেন্ট থেকে বাইরের দূরত্ব */
      margin: 30px;

      /* সাইজিং ঠিক রাখার জন্য recommended প্রপার্টি */
      box-sizing: border-box; 
    }
  </style>
</head>
<body>

  <div class="card">
    এটি একটি বক্স মডেলের উদাহরণ। এখানে কন্টেন্ট, প্যাডিং, বর্ডার এবং মার্জিন কাজ করছে।
  </div>

</body>
</html>
কোডটির বিশ্লেষণ:

Content: টেক্সটটি 300px চওড়া এবং 100px লম্বা জায়গায় অবস্থান করছে।

Padding: কন্টেন্টের চারপাশে 20px ফাঁকা জায়গা তৈরি হয়েছে, যার ফলে টেক্সটটি বর্ডারের গায়ে লেগে নেই।

Border: প্যাডিংয়ের বাইরে 5px চওড়া নীল রঙের একটি সীমানা তৈরি হয়েছে।

Margin: পুরো বক্সটি তার আশেপাশের জায়গা বা এলিমেন্ট থেকে 30px দূরে সরে এসেছে।

box-sizing: border-box: এটি ব্যবহার করায় padding এবং border যুক্ত হওয়ার পরেও পুরো বক্সটির মোট চওড়া ঠিক 300px-ই থাকবে।



******




১. Content (মূল কন্টেন্ট)

এটি বাক্সের কেন্দ্রীয় অংশ যেখানে আসল টেক্সট বা ছবি থাকে। width এবং height দিয়ে এর আকার ঠিক করা হয়।

CSS
.box {
  width: 300px;
  height: 150px;
  background-color: #e0f7fa; /* কন্টেন্ট এরিয়া স্পষ্ট বোঝার জন্য ব্যাকগ্রাউন্ড */
}
২. Padding (ভেতরের ফাঁকা জায়গা)

কন্টেন্ট এবং বর্ডারের ভেতরের মধ্যবর্তী দূরত্ব হলো প্যাডিং। এটি ব্যবহার করলে টেক্সট বর্ডারের গায়ে লেগে থাকে না।

CSS
.box {
  width: 300px;
  height: 150px;
  background-color: #e0f7fa;
  
  /* কন্টেন্টের চারপাশে ২০ পিক্সেল ভেতরের ফাঁকা জায়গা */
  padding: 20px; 
}
৩. Border (সীমানা)

প্যাডিং এবং কন্টেন্টকে ঘিরে যে বর্ডার বা সীমানা থাকে। এর মোটা-চিকন, রঙ এবং স্টাইল নির্ধারণ করা যায়।

CSS
.box {
  width: 300px;
  height: 150px;
  background-color: #e0f7fa;
  padding: 20px;
  
  /* ৫ পিক্সেল চওড়া নীল রঙের নিরেট বর্ডার */
  border: 5px solid #007bff; 
}
৪. Margin (বাইরের ফাঁকা জায়গা)

বর্ডারের বাইরের খালি জায়গা, যা এই বক্সটিকে আশেপাশের অন্যান্য HTML এলিমেন্ট থেকে নির্দিষ্ট দূরত্বে সরিয়ে রাখে।

CSS
.box {
  width: 300px;
  height: 150px;
  background-color: #e0f7fa;
  padding: 20px;
  border: 5px solid #007bff;
  
  /* বর্ডারের বাইরে চারপাশে ৩০ পিক্সেল ফাঁকা জায়গা */
  margin: 30px; 
}
৫. box-sizing: border-box; (বক্সের সঠিক সাইজ রাখা)

ডিফল্টভাবে প্যাডিং এবং বর্ডার যোগ করলে মোট বক্স বড় হয়ে যায়। কিন্তু এই প্রপার্টি ব্যবহার করলে প্যাডিং ও বর্ডার মূল width-এর ভেতরেই অ্যাডজাস্ট হয়ে সাইজ ঠিক রাখে।

CSS
.box {
  width: 300px;
  height: 150px;
  padding: 20px;
  border: 5px solid #007bff;
  margin: 30px;
  
  /* বক্সের মোট চওড়া ৩০০ পিক্সেলই থাকবে */
  box-sizing: border-box;
