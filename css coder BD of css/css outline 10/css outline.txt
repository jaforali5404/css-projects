CSS outline হলো একটি এলিমেন্টের বর্ডার বা সীমানার বাইরে আঁকা একটি রেখা। এটি দেখতে অনেকটা border-এর মতো হলেও কাজের দিক থেকে বেশ কিছু দৃশ্যমান ও কার্যগত পার্থক্য রয়েছে।

মূল বৈশিষ্ট্যসমূহ

জায়েগা নেয় না (No Layout Space): border দিলে এলিমেন্টের সাইজ বা মার্জিন-প্যাডিং পরিবর্তন হয়, কিন্তু outline বক্স-মডেলের অংশ নয়। তাই এটি পেইজের লেআউট বা সাইজে কোনো প্রভাব ফেলে না।

চারপাশে সমান: আপনি border-left বা border-top-এর মতো আলাদা আলাদা পাশে outline দিতে পারবেন না। দিলে পুরো চারপাশেই একসাথে দিতে হবে।

গোল করা যায় না: border-radius ব্যবহার করে বর্ডার গোল করা গেলেও outline সাধারণত গোল হয় না (এটি চারকোনা রেখা হিসেবেই থাকে)।

Outline-এর Short-hand Syntax

border-এর মতোই তিনটি প্রোপার্টি একসাথে ১টি লাইনে লেখা যায়: outline-width, outline-style, এবং outline-color।

CSS
/* syntax: outline: width style color; */
.button {
  outline: 2px solid red;
}
Outline-এর প্রোপার্টিসমূহ

outline-style: রেখাটি কেমন হবে (যেমন: solid, dashed, dotted, double, none)। এটি লেখা বাধ্যতামূলক, স্টাইল না দিলে আউটলাইন দেখা যাবে না।

outline-width: রেখাটি কতটুকু মোটা হবে (যেমন: 2px, thin, medium, thick)।

outline-color: রেখার রঙ কী হবে (যেমন: blue, #000000, rgb())।

outline-offset: এলিমেন্টের বর্ডার থেকে আউটলাইনটি কতটুকু দূরে সরবে তা নির্ধারণ করে। (যেমন: outline-offset: 4px;)

কখন ব্যবহার করা হয়?

১. Accessibility বা Focus State: ব্যবহারকারী যখন কীবোর্ডের Tab চেপে কোনো লিঙ্ক, ফর্ম বা বাটনে যান, তখন কোনটি সিলেক্ট হয়ে আছে তা বোঝাতে ব্রাউজার ডিফল্টভাবে একটি outline দেখায়।
২. Debugging: লেআউট ঠিক করার সময় কোনো এলিমেন্টের জায়গা চেক করতে outline ব্যবহার করা সুবিধাজনক, কারণ এতে লেআউট ভেঙে যায় না।

টিপস: outline: none; বা outline: 0; দিয়ে কখনো ব্রাউজারের ডিফল্ট ফোকাস আউটলাইন একেবারে বন্ধ করবেন না। এতে কীবোর্ড ব্যবহারকারীদের ওয়েবসাইটে নেভিগেট করতে সমস্যা হয়। উঠিয়ে দিতে চাইলে বিকল্প ফোকাস স্টাইল (:focus) ডিজাইন করে দিন।
