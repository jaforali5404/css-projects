CSS-এ Margin (মার্জিন) হলো একটি উপাদানের (Element) চারপাশের বাইরের খালি জায়গা বা স্পেস।সহজ কথায়, 
একটি উপাদান থেকে অন্য উপাদানকে কতটুকু দূরে রাখবেন, তা মার্জিন দিয়ে ঠিক করা হয়।
 এটি উপাদানটির বর্ডারের (Border) বাইরের অংশ নিয়ন্ত্রণ করে।১. মার্জিন কিভাবে কাজ করে?
মার্জিন ৪টি দিকে কাজ করে
:margin-top: ওপরের মার্জিন
margin-right: ডানপাশের মার্জিন
margin-bottom: নিচের মার্জিন
margin-left: বামপাশের মার্জিন
উদাহরণ:
CSSdiv {
  margin-top: 20px;
  margin-right: 15px;
  margin-bottom: 20px;
  margin-left: 15px;
}
২. Short-hand (সংক্ষিপ্ত) উপায়প্রতিটি দিক আলাদা করে না লিখে এক লাইনেই ৪টি দিকের মার্জিন লেখা যায়।
 এটি ঘড়ির কাটার দিকে (Top $\rightarrow$ Right $\rightarrow$ Bottom $\rightarrow$ Left) কাজ করে।
কোডের ধরনএর অর্থmargin: 10px 20px 30px 40px;        Top: 10px, Right: 20px, Bottom: 30px, Left: 40px
margin:10px 20px 30px;                          Top: 10px, Right & Left: 20px, Bottom: 30px
margin: 10px 20px;                              Top & Bottom: 10px, Right & Left: 20pxmargin: 10px;
চারপাশেই 10px৩. গুরুত্বপূর্ণ কিছু ব্যবহারক. 
কোনো উপাদানকে মাঝে আনা (Center Align)কোনো নির্দিষ্ট width দেওয়া ব্লক এলিমেন্টকে (যেমন div) পেজের ঠিক মাঝখানে নিতে margin: auto; বা margin: 0 auto; ব্যবহার করা হয়।
CSS.box {
  width: 500px;
  margin: 0 auto;/* উপরে-নিচে ০, ডানে-বামে স্বয়ংক্রিয়ভাবে সমান জায়গা নিবে */
}
খ. নেগেটিভ মার্জিন (Negative Margin)মার্জিনে মাইনাস (Negative) ভ্যালু ব্যবহার করা যায়। 
এতে একটি উপাদান অন্য উপাদানের ওপর উঠে যায় বা উপাদানের দিকে টেনে নেওয়া যায়।
CSS.image {
  margin-top: -20px; /* ছবিটিকে ২০ পিক্সেল ওপরে তুলে দেবে */
}
Margin এবং Padding-এর পার্থক্যঅনেকেই Margin এবং Padding মিলিয়ে ফেলেন:Margin: বর্ডারের বাইরের ফাঁকা জায়গা (অন্য উপাদান থেকে দূরত্ব তৈরি করে)।
Padding: বর্ডারের ভিতরের ফাঁকা জায়গা (কন্টেন্ট ও বর্ডারের মধ্যে দূরত্ব তৈরি করে)।
