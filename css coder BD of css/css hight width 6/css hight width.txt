CSS-এ ওয়েব পেজের যেকোনো এলিমেন্টের (যেমন: div, button, image) আকার বা সাইজ নির্ধারণ করতে height (উচ্চতা) এবং width (প্রস্থ) প্রপার্টি ব্যবহার করা হয়।
১. সাধারণ ভ্যালু বা একক (Units)এলিমেন্টের সাইজ নির্দিষ্ট করার জন্য সাধারণত ৩ ধরনের ইউনিট বেশি ব্যবহৃত হয়
:Pixel (px): নির্দিষ্ট সাইজ দিতে ব্যবহৃত হয় (যেমন: width: 300px; বা height: 150px;)। এটি স্ক্রিন ভেদে পরিবর্তন হয় না
।Percentage (%): প্যারেন্ট (Parent) এলিমেন্টের সাপেক্ষে আনুপাতিক সাইজ নির্ধারণ করে (যেমন: width: 50%; দিলে প্যারেন্ট ডিভের অর্ধেক জায়গা নেবে)।
Auto (auto): এটি ডিফল্ট ভ্যালু। ব্রাউজার নিজে থেকে কন্টেন্টের ওপর ভিত্তি করে প্রয়োজনীয় উচ্চতা ও প্রস্থ ঠিক করে নেয়।
২. Min এবং Max প্রপার্টি (রেসপন্সিভ ডিজাইনের জন্য)ওয়েবসাইটকে মোবাইল ও ডেক্সটপ—সব ডিভাইসে মানানসই করতে এগুলি ব্যবহার করা হয়
:max-width: এলিমেন্টের সর্বোচ্চ প্রস্থ নির্ধারণ করে। যেমন: max-width: 100%; ব্যবহার করলে কন্টেইনারের সাইজ ছোট হলে 
এলিমেন্টটিও স্ক্রিনের বাইরে না গিয়ে স্বয়ংক্রিয়ভাবে ছোট হয়ে যায়।min-height: এলিমেন্টের সর্বনিম্ন উচ্চতা ঠিক করে। কন্টেন্ট বাড়লে উচ্চতা নিচ থেকে নিজে থেকেই বাড়বে,
 কিন্তু নির্দিষ্ট সর্বনিম্ন সাইজের চেয়ে ছোট হবে না।
৩. জাদুকরী টিপস: box-sizing: border-boxডিফল্টভাবে CSS-এ width নির্ধারণ করলে তার সাথে padding এবং border যোগ হয়ে এলিমেন্টটি নির্ধারিত সাইজের চেয়ে বড় হয়ে যায়।
 এই সমস্যা সমাধানের জন্য সিএসএস-এ box-sizing: border-box; ব্যবহার করা হয়, যা প্যাডিং ও বর্ডারকে নির্দিষ্ট width-এর ভেতরেই সীমাবদ্ধ রাখে।CSS/* আদর্শ CSS রিসেট */
div {
  width: 300px;
  height: 200px;
  padding: 20px;
  box-sizing: border-box; /* এতে মূল প্রস্থ ৩০০ পিক্সেলই থাকবে */
}

২. রিয়েল-লাইফ কোড দিয়ে ব্যবধান বুঝুন
ধরা যাক, আমরা একটি বাটন তৈরি করছি:

CSS
button {
  /* ১. কন্টেন্টের সাইজ */
  width: 100px;
  height: 40px;

  /* ২. ভেতরের ফাঁকা জায়গা (লেখাকে বাটন এর বর্ডার থেকে সরাতে) */
  padding: 10px;

  /* ৩. চারপাশের দাগ বা ফ্রেম */
  border: 2px solid blue;

  /* ৪. বাইরের ফাঁকা জায়গা (অন্য উপাদান থেকে দূরে পাঠাতে) */
  margin: 20px;
}


****


সমস্যা ও সমাধান:আপনি যদি width: 200px দেন এবং সাথে padding: 20px ও border: 5px যুক্ত করেন, তবে স্ক্রিনে বাটনটি মোট 200 + 40 + 10 = 250px জায়গা নিয়ে নেবে,
 যা আপনার ডিজাইন নষ্ট করে দিতে পারে।সমাধান: এটি এড়াতে সিএসএস-এ box-sizing: border-box; ব্যবহার করা হয়। এটি দিলে আপনি যেই width নির্ধারণ করবেন, 
প্যাডিং ও বর্ডার তার ভেতরেই জায়গা করে নেবে—এলিমেন্টের আসল সাইজ বড় হবে না।
