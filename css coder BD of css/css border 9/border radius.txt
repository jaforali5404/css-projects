বর্ডার রেডিয়াস (Border Radius) হলো CSS (Cascading Style Sheets)-এর একটি প্রপার্টি, যা ব্যবহার করে ওয়েবসাইটের কোনো উপাদান বা এলিমেন্টের (যেমন: বাটন, ছবি, কার্ড ইত্যাদি) কোণাগুলোকে গোল বা বাঁকানো (Rounded) করা হয়।

মূল কাজ ও উদাহরণ

চারটি কোণা সমান করতে:

border-radius: 10px;

(এটি বক্সের চারটি কোণাকেই ১০ পিক্সেল পরিমাণ গোল করে দেবে।)

সম্পূর্ণ গোলাকার (Circle) করতে:

border-radius: 50%;

(কোনো বর্গাকার এলিমেন্টে ৫০% ব্যবহার করলে সেটি পুরোপুরি গোল বা বৃত্তে পরিণত হয়।)

আলাদা আলাদা কোণা বাঁকাতে

আপনি চাইলে একটি বক্সে চার কোণায় চার ধরনের মান ব্যবহার করতে পারেন:

border-radius: 10px 20px 30px 40px;

(ঘড়ির কাঁটার দিকে কাজ করে: উপর-বাম, উপর-ডান, নিচে-ডান, নিচে-বাম)

অথবা সুনির্দিষ্টভাবে লিখতে পারেন:

border-top-left-radius: 10px; (উপরের বাম কোণা)

border-top-right-radius: 10px; (উপরের ডান কোণা)

border-bottom-right-radius: 10px; (নিচের ডান কোণা)

border-bottom-left-radius: 10px; (নিচের বাম কোণা)

একক বা Units

বর্ডার রেডিয়াসে প্রধানত দুটি একক ব্যবহার করা হয়:

Pixels (px): নির্দিষ্ট এবং ফিক্সড সাইজ বাঁকানোর জন্য (যেমন: 8px, 15px)।

Percentage (%): রেসপন্সিভ বা উপাদানটির আকারের সাপেক্ষে বাঁকানোর জন্য (যেমন: 50%)।

ওয়েব ডিজাইনে বাটন, ইনপুট বক্স, কিংবা প্রোডাক্ট কার্ডকে সুন্দর ও আধুনিক রূপ দিতে বর্ডার রেডিয়াসের ব্যবহার সবচেয়ে বেশি দেখা যায়।
