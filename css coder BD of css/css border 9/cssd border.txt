CSS (Cascading Style Sheets)-এ Border বা বর্ডার ব্যবহার করা হয় কোনো HTML এলিমেন্টের চারপাশের সীমানা বা দাগ তৈরি করার জন্য।
 এটি ওয়েবসাইটের লেআউট সুন্দর ও সুনির্দিষ্ট করতে সাহায্য করে।

CSS বর্ডারের প্রধান তিনটি প্রপার্টি রয়েছে:

border-width: বর্ডারটি কতটা মোটা বা চিকন হবে (যেমন: 2px, 5px, thin, thick)।

border-style: বর্ডারটি দেখতে কেমন হবে (যেমন: solid, dashed, dotted ইত্যাদি)।

border-color: বর্ডারের রঙ কেমন হবে (যেমন: red, #000000, rgb(...))।

১. বর্ডার স্টাইলের ধরন (border-style)
বর্ডার দৃশ্যমান করার জন্য border-style প্রপার্টিটি দেওয়া বাধ্যতামূলক। কিছু জনপ্রিয় স্টাইল:

solid: একটি সাধারণ সোজা দাগ।

dashed: ড্যাশ বা ভাঙা ভাঙা দাগ (- - -)।

dotted: ছোট ছোট ডট বা বিন্দুর মতো (. . .)।

double: দুটি সমান্তরাল দাগ।

none: কোনো বর্ডার থাকবে না।

২. শর্টহ্যান্ড (Shorthand) ব্যবহার
তিনটি প্রপার্টি আলাদা আলাদা না লিখে এক লাইনেই লেখা সম্ভব। সংক্ষেপে লেখার নিয়মটি হলো:
border: [width] [style] [color];

উদাহরণ:

CSS
div {
  border: 2px solid blue;
}
(এখানে বর্ডারটি ২ পিক্সেল মোটা, সোজা বা সলিড এবং নীল রঙের হবে।)

৩. নির্দিষ্ট দিকে বর্ডার দেওয়া
আপনি চাইলে কোনো এলিমেন্টের চারপাশের যেকোনো এক বা একাধিক দিকে আলাদাভাবে বর্ডার দিতে পারেন:

border-top: শুধু ওপরের দিকে বর্ডার।

border-bottom: শুধু নিচের দিকে বর্ডার।

border-left: শুধু বাম পাশে বর্ডার।

border-right: শুধু ডান পাশে বর্ডার।

উদাহরণ:

CSS
h1 {
  border-bottom: 3px dashed red; /* লেখাটির নিচে একটি লাল ড্যাশ বর্ডার হবে */
}
৪. বর্ডার গোল করা (border-radius)
বর্ডারের কোণাগুলো সুন্দরভাবে গোল বা কার্ভ (Curve) করার জন্য border-radius ব্যবহার করা হয়।

CSS
button {
  border: 1px solid black;
  border-radius: 8px; /* কোণাগুলো ৮ পিক্সেল গোল হবে */
}
পরামর্শ: কোনো এলিমেন্টে বর্ডার না দেখতে পেলে খেয়াল করুন আপনি border-style ডিফাইন করেছেন কিনা। স্টাইল না দিলে বর্ডার সাধারণত অদৃশ্য থাকে!
