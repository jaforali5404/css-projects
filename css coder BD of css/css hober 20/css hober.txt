CSS-এ :hover হলো একটি অত্যন্ত গুরুত্বপূর্ণ Pseudo-class। যখন কোনো ইউজার মাউস কার্সার কোনো এলিমেন্টের (যেমন: বাটন, লিংক, ছবি বা কার্ড) ওপর নিয়ে যায় (Hover করে), তখন সেই এলিমেন্টের ডিজাইন বা স্টাইল পরিবর্তন করার জন্য এটি ব্যবহার করা হয়।

ওয়েবসাইটকে ইন্টারঅ্যাক্টিভ এবং আকর্ষণীয় করতে :hover ব্যবহার করা হয়।

মূল সিনট্যাক্স (Syntax)

CSS
selector:hover {
  /* মাউস নেওয়ার পর যেসব স্টাইল কাজ করবে */
  property: value;
}
সাধারণ কিছু ব্যবহারের উদাহরণ

১. বাটনের ব্যাকগ্রাউন্ড ও টেক্সট কালার পরিবর্তন

CSS
/* সাধারণ অবস্থা */
.btn {
  background-color: blue;
  color: white;
  padding: 10px 20px;
  border: none;
  transition: 0.3s; /* অ্যানিমেশন স্মুথ করার জন্য */
}

/* মাউস নেওয়ার পর */
.btn:hover {
  background-color: darkblue;
  color: yellow;
  cursor: pointer;
}
২. লিংকের আন্ডারলাইন প্রদর্শন

CSS
a {
  text-decoration: none;
  color: black;
}

a:hover {
  text-decoration: underline;
  color: red;
}
৩. ছবি বা কার্ড বড় করা (Zoom Effect)

CSS
.card {
  width: 200px;
  transition: transform 0.3s ease;
}

.card:hover {
  transform: scale(1.05); /* মাউস নিলে কার্ডটি ৫% বড় হবে */
}
গুরুত্বপূর্ণ কিছু টিপস

transition প্রোপার্টি ব্যবহার: :hover-এর সাথে transition ব্যবহার করলে স্টাইলের পরিবর্তনটা হঠাৎ না হয়ে খুব স্মুথ ও প্রফেশনাল দেখায়।

মোবাইল রেসপন্সিভনেস: স্মার্টফোন বা টাচ স্কিনে মাউস কার্সার থাকে না, তাই মোবাইল ডিভাইসে :hover ইফেক্ট সবসময় ঠিকমতো কাজ নাও করতে পারে (ট্যাপ করলে এটি ট্রিগার হয়)।

নির্দিষ্ট কোনো এলিমেন্টে :hover ইফেক্ট যোগ করতে কোনো সমস্যা হলে জানাবেন?


******


এর মাধ্যমে ব্যবহারকারীকে বোঝানো যায় যে কোনো এলিমেন্টে ক্লিক করা যাবে, টেক্সট সিলেক্ট করা যাবে, নাকি এলিমেন্টটি লোড হচ্ছে।

জনপ্রিয় কিছু Cursor Value

default: সাধারণ অ্যারো (Arrow) কার্সার দেখায়।

pointer: হাতের মতো আইকন দেখায়। সাধারণত বাটন বা লিংকের (Link) জন্য এটি ব্যবহার করা হয়, যা নির্দেশ করে এটিতে ক্লিক করা যাবে।

text: I অক্ষরের মতো আইকন দেখায়। টেক্সট ইনপুট ফিল্ড বা প্যারাগ্রাফের উপর টেক্সট সিলেক্ট করার জন্য এটি ব্যবহৃত হয়।

not-allowed: একটি লাল নিষিদ্ধ (Circle with slash) সাইন দেখায়। কোনো বাটন বা অপশন নিষ্ক্রিয় (Disabled) থাকলে এটি ব্যবহার করা হয়।

wait: লোডিং (Loading/Hourglass/Spinner) কার্সার দেখায়। ব্যাকগ্রাউন্ডে কোনো কাজ হওয়ার সময় এটি ব্যবহৃত হয়।

grab: কোনো কিছু ড্র্যাগ বা টেনে নেয়ার মতো হাতের পাঞ্জার আইকন দেখায়।

ব্যবহারের নিয়ম (Example):

CSS
/* বাটন এর ওপর মাউস নিলে হাতের আইকন দেখাবে */
button {
  cursor: pointer;
}

/* নিষ্ক্রিয় কোনো কিছুর ওপর মাউস নিলে নিষিদ্ধ সাইন দেখাবে */
.disabled-box {
  cursor: not-allowed;
}


******



CSS-এ কোনো এলিমেন্ট এক জায়গা থেকে অন্য জায়গায় সরানো বা মুভ করার নির্দেশ দিতে cursor: move; ব্যবহার করা হয়। এটি চারদিকে তিরচিহ্নযুক্ত একটি কার্সার (Crosshair/4-way arrow) দেখায়।

কোডের উদাহরণ:

CSS
.draggable-item {
  cursor: move;
}
HTML
<div class="draggable-item">
  এই বক্সটি ড্র্যাগ করে সরানো যাবে
</div>
আউটপুট কেমন দেখাবে:
যখন কেউ এই div বা এলিমেন্টের ওপর মাউস নিয়ে যাবে, তখন পয়েন্টারটি একটি ৪-দিক বিশিষ্ট অ্যারো চিহ্নে (✥) রূপান্তরিত হবে, যা ব্যবহারকারীকে বোঝায় যে এটি টেনে অন্য কোথাও সরিয়ে নেওয়া সম্ভব।
