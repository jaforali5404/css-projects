CSS-এ Pseudo-class (সুডো-ক্লাস) এবং Pseudo-element (সুডো-এলিমেন্ট) হলো এমন কিছু বিশেষ সিলেক্টর, 
যা HTML স্ট্রাকচারে সরাসরি ক্লাস বা এলিমেন্ট যোগ না করেই কোনো এলিমেন্টের নির্দিষ্ট অবস্থা বা নির্দিষ্ট অংশকে স্টাইল করতে ব্যবহৃত হয়।
১. Pseudo-class (সুডো-ক্লাস)Pseudo-class ব্যবহার করা হয় কোনো এলিমেন্টের বিশেষ অবস্থা বা স্টেট (State) সিলেক্ট করতে। 
এটি একটি সিঙ্গেল কোলন ( : ) দিয়ে লেখা হয়।পপুলার Pseudo-class সমূহের তালিকা ও ব্যবহার:Pseudo-classকখন কাজ করে / বিবরণ
:hoverব্যবহারকারী যখন মাউস কার্সার কোনো এলিমেন্টের ওপর আনে।:activeব্যবহারকারী যখন কোনো এলিমেন্টে (যেমন: বাটন) ক্লিক করে ধরে রাখে।
:focusইনপুট ফিল্ড বা এলিমেন্টে যখন ফোকাস/কার্সার থাকে।:visitedব্যবহারকারী ইতোমধ্যে যেসব লিংকে ভিজিট করেছে।
:nth-child(n)প্যারেন্ট এলিমেন্টের নির্দিষ্ট নম্বর (n) চাইল্ডকে সিলেক্ট করে।
:first-child / :last-childপ্রথম বা শেষ সন্তান (Child) এলিমেন্টকে সিলেক্ট করে।
:checkedচেকবক্স বা রেডিও বাটন সিলেক্ট করা (Checked) অবস্থায় থাকলে।
:not(selector)নির্দিষ্ট কোনো সিলেক্টর ছাড়া বাকি সব এলিমেন্টকে সিলেক্ট করে।উদাহরণ:CSS/* মাউস নিলে বাটনের ব্যাকগ্রাউন্ড পরিবর্তন */
button:hover {
  background-color: green;
  color: white;
}

/* ইনপুট বক্সে ফোকাস করলে বর্ডার নীল হবে */
input:focus {
  border-color: blue;
  outline: none;
}

/* তালিকার প্রতি ২য় (জোড়) আইটেম কালার করা */
li:nth-child(even) {
  background-color: #f2f2f2;
}
২. Pseudo-element (সুডো-এলিমেন্ট)Pseudo-element ব্যবহার করা হয় কোনো এলিমেন্টের নির্দিষ্ট অংশ বা ভার্চুয়াল অংশকে সিলেক্ট করতে।
 এটি সাধারণত ডাবল কোলন ( :: ) দিয়ে লেখা হয়।পপুলার Pseudo-element সমূহের তালিকা ও ব্যবহার:Pseudo-elementকখন কাজ করে / বিবরণ
::beforeএলিমেন্টের কন্টেন্টের ঠিক আগে নতুন কোনো কন্টেন্ট বা ডিজাইন যুক্ত করে।
::afterএলিমেন্টের কন্টেন্টের ঠিক পরে নতুন কোনো কন্টেন্ট বা ডিজাইন যুক্ত করে।
::first-letterকোনো টেক্সটের প্রথম অক্ষরটিকে সিলেক্ট করে।
::first-lineকোনো প্যারাগ্রাফের প্রথম লাইনটিকে সিলেক্ট করে।
::placeholderইনপুট ফিল্ডের প্লেসহোল্ডার টেক্সটকে স্টাইল করে।
::selectionব্যবহারকারী মাউস দিয়ে টেক্সট সিলেক্ট/হাইলাইট করলে কেমন দেখাবে তা নির্ধারণ করে।উদাহরণ:CSS/* প্যারাগ্রাফের প্রথম অক্ষর বড় ও লাল করা */
p::first-letter {
  font-size: 200%;
  color: red;
}

/* ইনপুট প্লেসহোল্ডারের কালার গ্রেই করা */
input::placeholder {
  color: #888;
  font-style: italic;
}

/* লিংকের আগে একটি আইকন বা সিম্বল যোগ করা (content ভ্যালু আবশ্যক) */
a::before {
  content: "👉 ";
}

/* টেক্সট হাইলাইট বা সিলেক্ট করলে ব্যাকগ্রাউন্ড হলুদ হবে */
::selection {
  background-color: yellow;
  color: black;
}
সংক্ষেপে পার্থক্য:Pseudo-class (:) $\rightarrow$ কোনো এলিমেন্টের অবস্থা বোঝায় (যেমন: ক্লিক করা, মাউস রাখা)।Pseudo-element (::) $\rightarrow$ কোনো এলিমেন্টের নির্দিষ্ট অংশ বোঝায় (যেমন: প্রথম অক্ষর, কন্টেন্টের আগের/পরের অংশ)।
