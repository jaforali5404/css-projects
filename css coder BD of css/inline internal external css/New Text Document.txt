সিএসএস (CSS) যোগ করার ৩টি ভিন্ন উপায় নিচে এলিমেন্ট ও উদাহরণসহ আলাদাভাবে দেখানো হলো:

১. ইনলাইন সিএসএস (Inline CSS)
যখন এইচটিএমএল (HTML) এলিমেন্টের ভেতরে সরাসরি style অ্যাট্রিবিউট ব্যবহার করে ডিজাইন করা হয়, তাকে ইনলাইন সিএসএস বলে।

HTML
<!DOCTYPE html>
<html>
<head>
    <title>Inline CSS Example</title>
</head>
<body>

    <!-- Inline CSS Element -->
    <h1 style="color: blue; text-align: center;">এটি একটি ইনলাইন সিএসএস হেডিং</h1>
    <p style="color: red; font-size: 18px;">এটি ইনলাইন সিএসএস দিয়ে ডিজাইন করা প্যারাগ্রাফ।</p>

</body>
</html>
২. ইন্টারনাল সিএসএস (Internal CSS)
যখন এইচটিএমএল ফাইলের <head> ট্যাগের ভেতরে <style> ট্যাগ ব্যবহার করে সিএসএস লেখা হয়, তাকে ইন্টারনাল সিএসএস বলে।

HTML
<!DOCTYPE html>
<html>
<head>
    <title>Internal CSS Example</title>
    <!-- Internal CSS Element & Rules -->
    <style>
        body {
            background-color: #f4f4f4;
        }
        h1 {
            color: green;
            text-align: center;
        }
        p {
            color: darkgray;
            font-size: 16px;
        }
    </style>
</head>
<body>

    <h1>এটি একটি ইন্টারনাল সিএসএস হেডিং</h1>
    <p>এটি ইন্টারনাল সিএসএস দিয়ে ডিজাইন করা প্যারাগ্রাফ।</p>

</body>
</html>
৩. এক্সটারনাল সিএসএস (External CSS)
যখন সিএসএস কোডগুলো আলাদা একটি .css ফাইলে (যেমন: style.css) লিখে, সেই ফাইলটিকে এইচটিএমএল ফাইলের সাথে <link> ট্যাগের মাধ্যমে যুক্ত করা হয়, তাকে এক্সটারনাল সিএসএস বলে।

এইচটিএমএল ফাইল (index.html):

HTML
<!DOCTYPE html>
<html>
<head>
    <title>External CSS Example</title>
    <!-- External CSS link Element -->
    <link rel="stylesheet" type="text/css" href="style.css">
</head>
<body>

    <h1>এটি একটি এক্সটারনাল সিএসএস হেডিং</h1>
    <p>এটি এক্সটারনাল সিএসএস দিয়ে ডিজাইন করা প্যারাগ্রাফ।</p>

</body>
</html>
আলাদা সিএসএস ফাইল (style.css):

CSS
body {
    background-color: #e0e0e0;
}

h1 {
    color: purple;
    text-align: center;
}

p {
    color: #333333;
    font-size: 20px;
}

CSS Specificity ও Priority নিয়ম জানুন

External CSS ফাইল যুক্ত করার বিস্তারিত শিখুন

External CSS ফাইল কীভাবে HTML-এর সাথে সঠিকভাবে যুক্ত করতে হয় এবং ফাইল পাথ (File Path) কীভাবে কাজ করে বুঝিয়ে দিন।

এইচটিএমএল (HTML) ফাইলের সাথে এক্সটারনাল সিএসএস (External CSS) ফাইল সঠিকভাবে যুক্ত করা এবং ফাইল পাথ (File Path) ঠিক রাখা ওয়েব ডিজাইনের একটি অত্যন্ত গুরুত্বপূর্ণ বিষয়। নিচে এটি সহজভাবে বুঝিয়ে দেওয়া হলো:

১. External CSS ফাইল কীভাবে যুক্ত করবেন?
এইচটিএমএল ফাইলের <head> সেকশনের ভেতরে <link> ট্যাগ ব্যবহার করে সিএসএস ফাইল যুক্ত করা হয়।

HTML
<head>
    <meta charset="UTF-8">
    <title>My Website</title>
    <!-- External CSS Link Element -->
    <link rel="stylesheet" href="style.css">
</head>
<link> ট্যাগের প্রধান অ্যাট্রিবিউটসমূহ:
rel="stylesheet": ব্রাউজারকে নির্দেশ করে যে যুক্ত করা ফাইলটি একটি স্টাইলশিট (Stylesheet)।

href="...": এখানে আপনার সিএসএস ফাইলটির ফাইল পাথ (File Path) বা ঠিকানা লিখতে হয়।

২. ফাইল পাথ (File Path) কীভাবে কাজ করে?
ফাইল পাথ হলো আপনার কম্পিউটার বা সার্ভারে ফাইলটি ঠিক কোন ফোল্ডারে বা স্থানে রাখা আছে তার ঠিকানা। এটি মূলত দুই প্রকার:

রিলেটিভ পাথ (Relative Path): এইচটিএমএল ফাইলের সাপেক্ষে সিএসএস ফাইলের অবস্থান। (এটিই সবচেয়ে বেশি ব্যবহৃত হয়)

অ্যাবসোলুট পাথ (Absolute Path): ফাইলের সম্পূর্ণ ইউআরএল (URL) বা সার্ভার লোকেশন।

৩. অ্যাবসোলুট পাথ (Absolute Path)
যদি আপনি সরাসরি ইন্টারনেটে থাকা কোনো সিএসএস ফাইল (যেমন: Bootstrap বা Google Fonts) বা সম্পূর্ণ সার্ভার ইউআরএল ব্যবহার করতে চান:

HTML
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.0.0/c
💡 সংক্ষিপ্ত টিপস:
./ = বর্তমান ফোল্ডার (Current Directory)।

../ = এক ধাপ ওপরের/পেছনের ফোল্ডার (Parent Directory)।

ফাইল এবং ফোল্ডারের নামে স্পেস (Space) ব্যবহার না করে হাইফেন (-) বা আন্ডারস্কোর (_) ব্যবহার করা উত্তম। (যেমন: my-style.css)

সিএসএস (CSS) এর ক্ষেত্রে প্রাইওরিটি (Priority) বা ক্যাসকেডিং (Cascading) এবং স্পেসিফিসিটি (Specificity) হলো এমন দুটি নিয়ম, যা নির্ধারণ করে কোনো একটি এইচটিএমএল (HTML) এলিমেন্টে একই সাথে একাধিক স্টাইল অ্যাপ্লাই করা হলে কোন স্টাইলটি কার্যকর হবে।১. Inline, Internal এবং External CSS-এর প্রাইওরিটি (Priority)সাধারণ নিয়ম অনুযায়ী, যে স্টাইলটি ব্রাউজারের সবচেয়ে কাছে বা শেষে থাকে, তার ক্ষমতা বা অগ্রাধিকার সবচেয়ে বেশি।অগ্রাধিকারের ক্রম (সবচেয়ে বেশি থেকে কম):$$\text{Inline CSS} > \text{Internal CSS / External CSS} > \text{Browser Default}$$১ম স্থান — Inline CSS (সবচেয়ে বেশি অগ্রাধিকার):HTML এলিমেন্টের গায়ে সরাসরি লেখা থাকায় এর ক্ষমতা সবচেয়ে বেশি। Inline CSS সাধারণত Internal এবং External CSS-কে ওভাররাইড (Override) বা অকার্যকর করে দেয়।২য় স্থান — Internal CSS এবং External CSS (সমান অগ্রাধিকার):ইন্টারনাল এবং এক্সটারনাল সিএসএস-এর মধ্যে যেটি <head> ট্যাগের ভেতরে পরে বা নিচে লেখা হবে, সেটির অগ্রাধিকার বেশি হবে।উদাহরণ ১: যদি External CSS লিঙ্কের নিচে Internal CSS থাকে, তবে Internal CSS কাজ করবে।উদাহরণ ২: যদি Internal CSS ট্যাগের নিচে External CSS লিঙ্ক করা থাকে, তবে External CSS কাজ করবে।৩য় স্থান — Browser Default Style (সবচেয়ে কম):ব্রাউজারের নিজস্ব কিছু ডিফল্ট স্টাইল থাকে (যেমন: <h1> ট্যাগের লেখা বড় হওয়া)। এটি সবচেয়ে কম অগ্রাধিকার পায়।⚠️ ব্যতিক্রম (!important Rule):যেকোনো CSS প্রপার্টির শেষে !important যোগ করলে তার প্রাইওরিটি সবকিছুর ওপরে চলে যায়—এমনকি Inline CSS-এর চেয়েও বেশি।(যেমন: color: red !important;)২. CSS Specificity কী এবং কীভাবে কাজ করে?যদি একাধিক External বা Internal CSS সিলেক্টর একই এলিমেন্টকে টার্গেট করে, তবে ব্রাউজার CSS Specificity (নির্দিষ্টতা) মেপে সিদ্ধান্ত নেয় কোনটি কার্যকর হবে।স্পেসিফিসিটিকে ৪টি স্তরের একটি পয়েন্ট সিস্টেম (Point System) হিসেবে হিসেব করা হয়:$$\text{( Inline , ID , Class/Pseudo-class/Attribute , Element/Pseudo-element )}$$সিলেক্টর টাইপ (Selector Type)উদাহরণপয়েন্ট (Score)ব্যাখ্যাInline Stylestyle="..."1, 0, 0, 0সরাসরি HTML-এ লেখা স্টাইল।ID Selector#header, #main0, 1, 0, 0ID দিয়ে টার্গেট করা।Class / Attribute / Pseudo-class.btn, [type="text"], :hover0, 0, 1, 0Class বা স্টেটস দিয়ে টার্গেট করা।Element / Pseudo-elementh1, p, div, ::before0, 0, 0, 1ট্যাগ বা এলিমেন্ট দিয়ে টার্গেট করা।Universal Selector*0, 0, 0, 0কোনো পয়েন্ট নেই (সবচেয়ে দুর্বল)।স্পেসিফিসিটি পয়েন্টের উদাহরণ:ধরা যাক, একটি প্যারাগ্রাফ <p id="text" class="content">Hello</p> আছে। একে সিএসএস-এ ৩ ভাবে টার্গেট করা হলো:CSS/* উদাহরণ ১: শুধুমাত্র এলিমেন্ট */
p { 
    color: red; 
} 
/* Point: 0, 0, 0, 1 */

/* উদাহরণ ২: ক্লাস দিয়ে টার্গেট */
.content { 
    color: blue; 
} 
/* Point: 0, 0, 1, 0 */

/* উদাহরণ ৩: আইডি দিয়ে টার্গেট */
#text { 
    color: green; 
} 
/* Point: 0, 1, 0, 0 */
ফলাফল: এখানে পয়েন্ট সবচেয়ে বেশি #text এর (0,1,0,0)। তাই প্যারাগ্রাফের রঙ সবুজ (Green) হবে।স্পেসিফিসিটির ৪টি গোল্ডেন রুলস (Golden Rules):বাম থেকে ডানের পয়েন্ট আগে দেখা হয়: 0, 1, 0, 0 (একটি ID) সব সময় 0, 0, 15, 0 (১৫টি Class)-এর চেয়ে শক্তিশালী।পয়েন্ট সমান হলে শেষেরটি জিতবে: যদি দুটি সিলেক্টরের পয়েন্ট হুবহু সমান হয় (যেমন দুটিই 0,0,1,0), তবে কোডে যেটি নিচে লেখা হয়েছে সেটি কাজ করবে।কম্বিনেশন স্কোর যোগ হয়: div.content p সিলেক্টরের পয়েন্ট হবে: $2 \times \text{Element} (0,0,0,2) + 1 \times \text{Class} (0,0,1,0) = (0,0,1,2)$।!important সব নিয়ম ভেঙে দেয়: এটি স্পেসিফিসিটির পয়েন্ট হিসেব না করে সরাসরি স্টাইল অ্যাপ্লাই করে দেয়। (প্রজেক্টে অপ্রয়োজনে !important ব্যবহার না করাই ভালো)।
