CSS-এ background-color প্রপার্টি ব্যবহার করে যেকোনো HTML ელিমেন্টের পেছনে একটি নির্দিষ্ট রঙ (Color) সেট করা হয়।

মূল বিষয়সমূহ:

ডিফল্ট মান: অধিকাংশ এলিমেন্টের ডিফল্ট ব্যাকগ্রাউন্ড কালার থাকে transparent (স্বচ্ছ)। ফলে এর পেছনের এলিমেন্ট বা ব্যাকগ্রাউন্ড দেখা যায়।

প্রয়োগক্ষেত্র: এটি HTML-এর প্রায় সব Element-এ (যেমন: <body>, <div>, <h1>, <p>, <button>, <table> ইত্যাদি) ব্যবহার করা যায়।

ইনহেরিটেন্স: ব্যাকগ্রাউন্ড কালার সাধারণত চাইল্ড এলিমেন্টে স্বয়ংক্রিয়ভাবে ইনহেরিট (Inherit) হয় না, তবে প্যারেন্ট এলিমেন্টের ব্যাকগ্রাউন্ড স্বচ্ছ থাকায় নিচের রঙটি দেখা যায়।

রঙ নির্ধারণের পদ্ধতি (Color Values):

Color Name: সরাসরি রঙের নাম (যেমন: red, blue, green)

HEX Code: ৬ বা ৩ ডিজিটের হেক্স কোড (যেমন: #ff0000, #333)

RGB / RGBA: লাল, সবুজ ও নীল রঙের মিশ্রণ (যেমন: rgb(255, 0, 0) এবং ওবাসিটি বা স্বচ্ছতার জন্য rgba(0, 0, 255, 0.5))

HSL / HSLA: Hue, Saturation, Lightness দিয়ে (যেমন: hsl(120, 100%, 50%))

উদাহরণ:

CSS
/* পুরো পেজের ব্যাকগ্রাউন্ড */
body {
  background-color: #f4f4f4;
}

/* নির্দিষ্ট কোনো সেকশন বা div-এর ব্যাকগ্রাউন্ড */
div {
  background-color: blue;
}

/* বাটন এবং টেক্সট হালকা স্বচ্ছ করার জন্য RGBA */
button {
  background-color: rgba(255, 0, 0, 0.7);
}

CSS-এ linear-gradient() ফাংশন ব্যবহার করে দুই বা ততোধিক রঙের মধ্যে একটি সোজা রেখা (Linear Line) বরাবর মসৃণ পরিবর্তন (Transition) তৈরি করা হয়। এটি ব্যাকগ্রাউন্ডকে আকর্ষণীয় করতে ফ্ল্যাট কালারের বিকল্প হিসেবে background বা background-image প্রপার্টিতে ব্যবহৃত হয়।মৌলিক সিনট্যাক্স (Syntax):CSSbackground: linear-gradient(direction/angle, color1, color2, ...);
ব্যবহারের ধরনসমূহ:১. ডিফল্ট (উপরিভাগ থেকে নিচে):দিক নির্দিষ্ট না করলে স্বয়ংক্রিয়ভাবে উপর থেকে নিচে রঙ পরিবর্তন হয়।CSSdiv {
  background: linear-gradient(red, yellow);
}
২. দিক নির্ধারণ (Direction):to right, to left, to top, to bottom right ইত্যাদি দিয়ে দিক সেট করা যায়।CSSdiv {
  /* বাম থেকে ডান দিকে */
  background: linear-gradient(to right, red, yellow);
}
৩. কোণ নির্ধারণ (Angle):ডিগ্রি (deg) ব্যবহার করে যেকোনো কোণে গ্র্যাডিয়েন্ট ঘোরানো যায় (যেমন: 0deg, 45deg, 90deg, 180deg)।CSSdiv {
  /* ৪৫ ডিগ্রি কোণে */
  background: linear-gradient(45deg, blue, red);
}
৪. একাধিক রঙ ও পার্সেন্টেজ (Multiple Colors & Stops):দুইয়ের অধিক রঙ এবং কোন রঙ কতটুকু জুড়ে থাকবে তা নির্দিষ্ট করে দেওয়া যায়।CSSdiv {
  /* ৩টি রঙ এবং নির্দিষ্ট স্থান */
  background: linear-gradient(to right, red 0%, green 50%, blue 100%);
}

CSS-এ radial-gradient() মূলত কেন্দ্রবিন্দু থেকে চারদিকে বৃত্তাকারে বা ডিম্বাকারে (ellipse) রঙের পরিবর্তন তৈরি করতে ব্যবহৃত হয়।

এর প্রধান উপাদানগুলো নিচে দেওয়া হলো:

Shape (আকার): গ্র্যাডিয়েন্টটি কেমন হবে তা নির্ধারণ করে।

circle: নিখুঁত বৃত্তাকার গ্র্যাডিয়েন্ট।

ellipse: ডিম্বাকার গ্র্যাডিয়েন্ট (এটি ডিফল্ট আকার)।

Size (আয়তন): গ্র্যাডিয়েন্টটি কত দূর পর্যন্ত বিস্তৃত হবে তা ঠিক করে।

closest-side: কেন্দ্র থেকে সবচেয়ে কাছের প্রান্ত পর্যন্ত।

farthest-side: কেন্দ্র থেকে সবচেয়ে দূরের প্রান্ত পর্যন্ত।

closest-corner: কেন্দ্র থেকে সবচেয়ে কাছের কোণ পর্যন্ত।

farthest-corner: কেন্দ্র থেকে সবচেয়ে দূরের কোণ পর্যন্ত (এটি ডিফল্ট)।

নির্দিষ্ট দৈর্ঘ্য (যেমন: 50px 50px) বা শতাংশ।

Position (অবস্থান): গ্র্যাডিয়েন্টের কেন্দ্রবিন্দুটি কোথায় থাকবে তা নির্ধারণ করে। at কিউওয়ার্ড ব্যবহার করে অবস্থান দিতে হয় (যেমন: at center, at top left, বা at 50% 50%)।

Color Stops (রঙের অবস্থান): গ্র্যাডিয়েন্টে কোন কোন রঙ থাকবে এবং সেগুলো কোথায় গিয়ে পরিবর্তন হবে তা নির্দেশ করে। অন্তত ২টি রঙের প্রয়োজন হয় (যেমন: red 20%, blue 80%)।

সিনট্যাক্স ও উদাহরণ:

CSS
background: radial-gradient(shape size at position, color-stop1, color-stop2, ...);
ব্যবহারিক উদাহরণ:

CSS
/* কেন্দ্রের উপরে বাম কোণ থেকে তৈরি বৃত্তাকার গ্র্যাডিয়েন্ট */
background: radial-gradient(circle at top left, yellow, red, black);

CSS-এ কোনো উপাদানের ব্যাকগ্রাউন্ডে ইমেজ সেট করার জন্য এবং সেটি নিয়ন্ত্রণ করার জন্য বেশ কিছু গুরুত্বপূর্ণ প্রপার্টি ব্যবহার করা হয়। নিচে এগুলো ধারাবাহিকভাবে আলোচনা করা হলো:

মূল CSS Background Image প্রপার্টিসমূহ

background-image: এটি দিয়ে ব্যাকগ্রাউন্ডে ছবি যুক্ত করা হয়।

উদাহরণ: background-image: url('image.jpg');

background-repeat: ছবিটি বারবার রিপিট হবে নাকি একবার দেখাবে তা নির্ধারণ করে।

repeat: আড়াআড়ি ও লম্বালম্বি দুই দিকেই রিপিট হয় (ডিফল্ট)।

no-repeat: ছবি রিপিট হবে না, একবারই দেখাবে।

repeat-x: শুধু ডানে-বামে (Horizontal) রিপিট হবে।

repeat-y: শুধু উপরে-নিচে (Vertical) রিপিট হবে।

background-size: ছবির সাইজ বা আকার কেমন হবে তা নিয়ন্ত্রণ করে।

cover: পুরো কন্টেইনার জুড়ে ছবিটি ছড়িয়ে পড়ে (কিছু অংশ কেটে যেতে পারে, কিন্তু জায়গা ফাঁকা থাকবে না)।

contain: ছবিটি না কেটে পুরোটা দেখায় (জায়গা ফাঁকা থাকতে পারে)।

100% 100% বানির্দিষ্ট পিক্সেল (300px 200px): নিজের মতো সাইজ দেওয়া যায়।

background-position: কন্টেইনারের কোথায় ছবি বসবে তা ঠিক করে।

মানসমূহ: center, top, bottom, left, right বা পিক্সেল/পার্সেন্টেজ (যেমন: center center, 50% 50%, 20px 40px)।

background-attachment: স্ক্রোল করার সময় ছবি এক জায়গায় নির্দিষ্ট থাকবে নাকি স্ক্রোল হবে তা ঠিক করে।

scroll: পেজ স্ক্রোল করলে ছবিও সাথে সাথে স্ক্রোল হবে (ডিফল্ট)।

fixed: পেজ স্ক্রোল করলেও ছবি এক জায়গায় স্থির থাকবে (Parallax Effect-এর জন্য ব্যবহৃত হয়)।

background-origin: ছবির পজিশন বা অবস্থান কোত্থেকে শুরু হবে তা নির্ধারণ করে।

border-box: বর্ডারের একদম বাহিরের সীমানা থেকে শুরু হয়।

padding-box: ಪ್ಯಾডিঙের ভেতর থেকে শুরু হয় (ডিফল্ট)।

content-box: শুধু কন্টেন্টের ভেতর থেকে শুরু হয়।

background-clip: ছবির কতটুকু অংশ দৃশ্যমান হবে তা নির্ধারণ করে।

border-box, padding-box, content-box (উপরি উক্ত নিয়মানুযায়ী ব্যাকগ্রাউন্ড কাটছাঁট হয়)।

Shorthand Property (সংক্ষিপ্ত রূপ)

সবগুলো প্রপার্টি আলাদা না লিখে একসাথে background প্রপার্টি দিয়ে লেখা যায়:

CSS
div {
  background: url('image.jpg') no-repeat center/cover fixed;
}

CSS-এর background-blend-mode প্রপার্টি ব্যবহার করে কোনো এলিমেন্টের ব্যাকগ্রাউন্ড ইমেজ (Background Image) এবং ব্যাকগ্রাউন্ড কালার (Background Color) অথবা একাধিক ব্যাকগ্রাউন্ড ইমেজের মধ্যে ব্লেন্ডিং (Blending/Mix) তৈরি করা হয়। ফটোশপ বা কোনো ইমেজ এডিটিং সফটওয়্যারে যেভাবে লেয়ারের 'Blend Mode' কাজ করে, ওয়েব ডিজাইনে এটি ঠিক একইভাবে কাজ করে।

কখন ব্যবহার করা হয়?

ছবির ওপর রঙের ফিল্টার বা ওভারলে (Overlay) তৈরি করতে।

একাধিক ব্যাকগ্রাউন্ড ইমেজকে একটার সাথে অন্যটি সুন্দরভাবে মিশিয়ে দিতে।

ছবির ব্রাইটনেস, কন্ট্রাস্ট বা কালার টোন অ্যাডজাস্ট করতে ফটোশপ ব্যবহার না করেই সরাসরি CSS দিয়ে কাজ সারতে।

সাধারণ সিনট্যাক্স (Syntax)

CSS
.my-element {
  background-image: url('image.jpg');
  background-color: #ff0000;
  background-blend-mode: multiply; /* Blend Value */
}
জনপ্রিয় Blend Mode القيمসমূহ

normal: এটি ডিফল্ট মোড। কোনো ব্লেন্ডিং হবে না, যা ওপরের স্তরে আছে সেটাই দেখা যাবে।

multiply: ব্যাকগ্রাউন্ড কালার ও ইমেজকে গুণ করে একটি ডার্ক বা গাঢ় ব্যাকগ্রাউন্ড তৈরি করে। (ছবির ওপর রঙিন ডার্ক ফিল্টার দিতে সেরা)।

screen: এটি ছবির ওপরের অংশকে ব্রাইট বা উজ্জ্বল করে তোলে।

overlay: এটি multiply এবং screen-এর একটি মিশ্রণ। ছবির হাইলাইট ও শ্যাডো বজায় রেখে রঙ ব্লেণ্ড করে।

darken: ব্যাকগ্রাউন্ড ইমেজ এবং কালারের মধ্যে যে রঙটি বেশি গাঢ়, সেটি বজায় রাখে।

lighten: ব্যাকগ্রাউন্ড ইমেজ এবং কালারের মধ্যে যে রঙটি বেশি হালকা, সেটি বজায় রাখে।

color-dodge: ছবিকে আরও ব্রাইট করে ও কালার স্যাচুরেশন বাড়ায়।

color-burn: ছবিকে ডার্ক করে এবং কনট্রাস্ট বাড়িয়ে দেয়।

luminosity: ব্যাকগ্রাউন্ডের লুমিনোসিটি বা ব্রাইটনেস লেভেল ধরে রেখে ব্লেন্ড করে (যেমন: কালারফুল ছবিকে ব্ল্যাক অ্যান্ড হোয়াইট টোন দেওয়া)।

কোড উদাহরণ

HTML
<div class="card"></div>
CSS
.card {
  width: 400px;
  height: 250px;
  background-image: url('nature.jpg');
  background-color: rgba(0, 0, 255, 0.5); /* নীল রঙ */
  background-size: cover;
  background-blend-mode: overlay; /* এখানে ব্লেন্ডিং কার্যকর হবে */
}
background-blend-mode এবং mix-blend-mode-এর পার্থক্য

background-blend-mode: শুধুমাত্র একটি নির্দিষ্ট এলিমেন্টের ভেতরের ব্যাকগ্রাউন্ড ইমেজ ও ব্যাকগ্রাউন্ড কালারের মধ্যে কাজ করে।

mix-blend-mode: একটি পুরো এলিমেন্টকে (যেমন: <p>, <h1> বা <img>) তার পেছনের অন্য কোনো এলিমেন্টের সাথে ব্লেন্ড করে।
