CSS Math Functions হলো এমন কিছু ফাংশন যার মাধ্যমে কোনো স্টাইল বা লেআউটে সরাসরি গাণিতিক হিসাব-নিকাশ করা যায়। এগুলো আলাদা JavaScript ব্যবহার না করেই আপনার CSS-কে অত্যন্ত রেসপনসিভ ও ডায়নামিক করে তোলে।CSS-এ ব্যবহৃত প্রধান Math Function-গুলো, তাদের বিভিন্ন element (উপাদান) এবং মানসহ (values) উদাহরণ নিচে বিস্তারিতভাবে দেওয়া হলো:১. calc() – সাধারণ গাণিতিক হিসাবcalc() ফাংশন ব্যবহার করে আপনি বিভিন্ন ইউনিট (যেমন: %, px, rem, vw) একসাথে যোগ, বিয়োগ, গুণ বা ভাগ করতে পারবেন।গাণিতিক Element/Operator: + (যোগ), - (বিয়োগ), * (গুণ), / (ভাগ)।নিয়ম: যোগ (+) ও বিয়োগ (-) চিহ্নের দুই পাশে অবশ্যই স্পেস (Space) দিতে হবে।CSS.card {
  /* পুরো স্ক্রিনের ১০০% প্রস্থ থেকে ৫০ পিক্সেল বিয়োগ */
  width: calc(100% - 50px);
  
  /* প্যাডিং হিসাব: ৩ রেম এর সাথে গুণ */
  padding: calc(1rem * 2);
}
২. min() – সর্বনিম্ন মান নির্ধারণmin() ফাংশন ব্র্যাকেটের ভেতরের মানগুলোর মধ্যে যা সবচেয়ে ছোট, সেটি নির্বাচন করে। এটি রেসপনসিভ ডিজাইনে কোনো উপাদানের সর্বোচ্চ সীমা বা Max-width সেট করতে চমৎকার কাজ করে।Element/Value: কমা (,) দিয়ে আলাদা করা একাধিক সাইজ বা মান।CSS.container {
  /* স্ক্রিনের প্রস্থ অনুযায়ী ৫০% অথবা ৬০০ পিক্সেল — এই দুটির মধ্যে যেটি ছোট হবে সেটি প্রয়োগ হবে */
  width: min(50vw, 600px);
}
৩. max() – সর্বোচ্চ মান নির্ধারণmax() ফাংশন ব্র্যাকেটের ভেতরের মানগুলোর মধ্যে যা সবচেয়ে বড়, সেটি নির্বাচন করে। কোনো এলিমেন্ট যেন নির্দিষ্ট সাইজের চেয়ে বেশি ছোট না হয়ে যায় (Min-width), তার জন্য এটি ব্যবহার করা হয়।Element/Value: কমা (,) দিয়ে আলাদা করা একাধিক সাইজ বা মান।CSS.title {
  /* ৪ ভিউপোর্ট উইডথ (4vw) অথবা ২০ পিক্সেল — এই দুটির মধ্যে যেটি বড় হবে সেটি প্রয়োগ হবে */
  font-size: max(4vw, 20px);
}
৪. clamp() – সীমার মধ্যে মান নির্ধারণ (Min, Preferred, Max)clamp() একটি ফ্লুইড টাইপোগ্রাফি ও রেসপনসিভ লেআউট তৈরির জন্য সবচেয়ে দরকারী ফাংশন। এটি মানকে একটি নির্দিষ্ট সীমার (Range) মধ্যে আটকে রাখে।Element/Value Structure: clamp(MIN, PREFERRED, MAX)MIN: সর্বনিম্ন কত হতে পারবে (মান এর নিচে নামবে না)।PREFERRED: স্বাভাবিক বা রেসপনসিভ পছন্দসই মান (যেমন: vw বা %)।MAX: সর্বোচ্চ কত হতে পারবে (মান এর উপরে উঠবে না)।CSS.responsive-heading {
  /* সর্বনিম্ন ১.৫ রেম, স্ক্রিন অনুযায়ী ৫ ভিউপোর্ট উইডথ, এবং সর্বোচ্চ ৩ রেম */
  font-size: clamp(1.5rem, 5vw, 3rem);
}
৫. mod() এবং rem() – ভাগশেষ (Remainder) নির্ণয়এই দুটি ফাংশন ভাগ করার পর কত অবশিষ্ট/ভাগশেষ থাকে তা বের করে।mod(A, B): Truncated Division (মান ঋণাত্মক হলেও ফলাফল B-এর চিহ্নের সাথে মেলে)।rem(A, B): Standard Modulo (ফলাফল A-এর চিহ্নের সাথে মেলে)।Element/Value: প্রথম মান (dividend) এবং দ্বিতীয় মান (divisor)।CSS.grid-item {
  /* ৮০০ পিক্সেলকে ১৫০ দিয়ে ভাগ করার পর যে ভাগশেষ থাকে তা মার্জিন হিসেবে বসবে */
  margin-left: mod(800px, 150px); /* Output: 50px */
}
৬. round() – পূর্ণসংখ্যায় রূপান্তর (Rounding)এটি কোনো দশমিক মানকে নিকটস্থ পূর্ণসংখ্যা বা নির্দিষ্ট কোনো মান অনুসারে রাউন্ড করে।Element/Value Structure: round(STRATEGY, VALUE, STEP)STRATEGY (ঐচ্ছিক): nearest (ডিফল্ট), up (উপরে/ceil), down (নিচে/floor), to-zero (শূন্যের দিকে)।VALUE: মূল মান।STEP: কত পিক্সেল বা ইউনিটের ব্যবধানে রাউন্ড হবে।CSS.box {
  /* ৩১৫ পিক্সেলকে ১০০ পিক্সেলের সাপেক্ষে নিকটস্থ মান (৩০০ পিক্সেল)-এ রাউন্ড করবে */
  width: round(nearest, 315px, 100px); /* Output: 300px */
}
৭. Trigonometric Functions – ত্রিকোণমিতিক ফাংশনCSS-এ অ্যানিমেশন বা ত্রিকোণমিতিক লেআউট হিসেব করার জন্য আধুনিক এই ফাংশনগুলো ব্যবহার করা হয়:sin() – সাইন মানcos() – কোসাইন মানtan() – ট্যানজেন্ট মানasin(), acos(), atan(), atan2() – ইনভার্স ত্রিকোণমিতিElement/Value: কোণের মান deg (ডিগ্রি) বা rad (রেডিয়ান)-এ দিতে হয়।CSS.rotated-element {
  /* ৪৫ ডিগ্রি কোণের কোসাইন মান হিসেব করে স্কেলিং করা */
  transform: scale(cos(45deg));
}
৮. Advanced Exponential Functions – সূচকীয় ফাংশনজটিল ডায়নামিক ক্যালকুলেশনের জন্য এগুলো ব্যবহৃত হয়:pow(A, B) – A এর পাওয়ার B ($A^B$)। যেমন: pow(2, 3) = 8।sqrt(A) – A এর বর্গমূল ($\sqrt{A}$)। যেমন: sqrt(100px) = 10px।hypot(A, B, ...) – বাহুগুলোর বর্গমূলের যোগফল ($\sqrt{A^2 + B^2}$)।log(A) – প্রাকৃতিক লগারিদম।exp(A) – $e^A$ মান হিসেব করা।CSS.card-3d {
  /* ৩ এবং ৪ এর হাইপোটেনাস/অতিভুজ নির্ণয় (ফলাফল: ৫ রেম) */
  padding: hypot(3rem, 4rem); 
}
৯. abs() এবং sign() – মান ও চিহ্ন রূপান্তরabs(A) – ঋণাত্মক মানকে ধন্যাত্মক (Absolute Value) করে দেয়। যেমন: abs(-20px) = 20px।sign(A) – সংখ্যার চিহ্ন নির্দেশ করে। ধন্যাত্মক হলে 1, ঋণাত্মক হলে -1 এবং ০ হলে 0 প্রদান করে।CSS.element {
  /* ঋণাত্মক ৫০ পিক্সেলকে পজিটিভ ৫০ পিক্সেলে রূপান্তর করবে */
  top: abs(-50px); 
}
