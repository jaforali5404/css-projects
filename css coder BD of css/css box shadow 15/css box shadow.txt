CSS-এ box-shadow প্রোপার্টি ব্যবহার করে কোনো এলিমেন্টের (যেমন: div, card, button) চারপাশে ড্রপ শ্যাডো বা ছায়া তৈরি করা হয়।

এর বেসিক সিনট্যাক্সটি হলো:

CSS
box-shadow: [offset-x] [offset-y] [blur-radius] [spread-radius] [color] [inset];
offset-x: ছায়াটি ডানে বা বামে কতটা সরবে। (পজিটিভ মান দিলে ডানে, নেগেটিভ মান দিলে বামে)

offset-y: ছায়াটি ওপরে বা নিচে কতটা সরবে। (পজিটিভ মান দিলে নিচে, নেগেটিভ মান দিলে ওপরে)

blur-radius: ছায়াটি কতটা ঝাপসা (blur) হবে। (ঐচ্ছিক, মান যত বেশি ছায়া তত হালকা)

spread-radius: ছায়াটি চারদিকে কতটা ছড়াবে। (ঐচ্ছিক, পজিটিভ মান ছায়া বাড়ায়, নেগেটিভ কমায়)

color: ছায়ার রঙ।

inset: এটি ব্যবহার করলে ছায়াটি এলিমেন্টের ভেতরের দিকে তৈরি হয়। (ঐচ্ছিক)

প্র্যাকটিক্যাল উদাহরণ:

১. সাধারণ ছায়া (Soft Card Shadow):

CSS
box-shadow: 0px 4px 10px rgba(0, 0, 0, 0.15);
(কার্ড বা বক্স সুন্দর দেখানোর জন্য এই ধরনের হালকা ছায়া সবচেয়ে বেশি ব্যবহৃত হয়)

২. গ্লো ইফেক্ট (Glow Effect):

CSS
box-shadow: 0px 0px 15px #940c0c;
(এখানে offset-x ও offset-y শূন্য রাখায় ছায়াটি সবদিকে সমানভাবে ছড়িয়ে একটা গ্লো তৈরি করে)

৩. ইনসেট বা ভেতরের ছায়া (Inner Shadow):

CSS
box-shadow: inset 0px 2px 5px rgba(0, 0, 0, 0.3);
৪. একাধিক ছায়া (Multiple Shadows):

CSS
box-shadow: 0px 5px 10px red, 0px 10px 20px blue;
(কমা ব্যবহার করে একাধিক শ্যাডো একসাথে প্রয়োগ করা যায়)


******



আপনার দেওয়া box-shadow: 0px 5px 15px; কোডটিতে ৩টি মান (Value) রয়েছে।  
এগুলোর কাজ নিচে ধাপে ধাপে দেওয়া হলো:
১ম মান (0px) — Offset-X (ডানে/বামে সরানো):
ছায়াটি বামে বা ডানে সরবে না, ঠিক বক্সের মাঝবরোবর থাকবে। (পজিটিভ দিলে ডানে যেত, নেগেটিভ দিলে বামে যেত) 
।২য় মান (5px) — Offset-Y (উপরে/নিচে সরানো):
ছায়াটিকে বক্সের নিচ দিয়ে ৫ পিক্সেল নামিয়ে দেওয়া হয়েছে। এর ফলে মনে হবে বক্সটি টেবিল বা ব্যাকগ্রাউন্ড থেকে একটু ওপরে ভেসে আছে।
৩য় মান (15px) — Blur Radius (ঝাপসা করা):
ছায়ার চারপাশের ধারগুলো ১৫ পিক্সেল পরিমাণ ধোঁয়ার মতো নরম ও ঝাপসা করা হয়েছে। এই মানটি যত বেশি হবে,
 ছায়াটি দেখতে তত বেশি প্রাকৃতিক ও হালকা মনে হবে।(নোট: এখানে কোনো রঙের কথা বলা হয়নি, তাই ব্রাউজার ডিফল্টভাবে আপনার টেক্সটের রঙ বা কালো রঙকে ছায়া হিসেবে ধরে নেবে।)
