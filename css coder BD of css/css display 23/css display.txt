CSS-এ display প্রপার্টি অত্যন্ত গুরুত্বপূর্ণ, কারণ এটি নির্ধারণ করে একটি HTML এলিমেন্ট ওয়েব পেজে কীভাবে রেন্ডার হবে বা জায়গা নেবে।প্রধান display প্রপার্টিগুলোর বিস্তারিত ব্যাখ্যা ও উদাহরণ নিচে দেওয়া হলো:১. display: blockব্যাখ্যা: এই এলিমেন্টগুলো স্ক্রিনের সম্পূর্ণ প্রস্থ (Width 100%) দখল করে এবং নতুন লাইনে শুরু হয়। এদের width এবং height সেট করা যায়।ডিফল্ট এলিমেন্ট: <div>, <p>, <h1> - <h6>, <section>।CSSdiv {
  display: block;
  width: 200px;
  background-color: lightblue;
}
ব্যাখ্যা: এখানে div টি স্ক্রিনের নতুন লাইনে শুরু হবে এবং 지정 করা 200px প্রস্থ নিয়ে থাকবে।২. display: inlineব্যাখ্যা: এই এলিমেন্টগুলো নতুন লাইনে শুরু হয় না; কেবল কনটেন্ট যতটুকু, ততটুকু জায়গা নেয়। এতে width বা height সেট করা যায় না।ডিফল্ট এলিমেন্ট: <span>, <a>, <b>, <i>।CSSspan {
  display: inline;
  color: red;
}
ব্যাখ্যা: লেখার ভেতরের কোনো নির্দিষ্ট শব্দ বা অংশকে আলাদা স্টাইল দিতে inline ব্যবহার করা হয়। এটি অন্য টেক্সটের সাথেই একই লাইনে থাকবে।৩. display: inline-blockব্যাখ্যা: এটি inline এবং block উভয়ের সংমিশ্রণ। এলিমেন্টগুলো একই লাইনে পাশাপাশি থাকবে (inline-এর মতো), কিন্তু এদের width এবং height পরিবর্তন করা যাবে (block-এর মতো)।CSS.button {
  display: inline-block;
  width: 120px;
  height: 40px;
  background-color: green;
}
ব্যাখ্যা: বাটন বা নেভিগেশন বারের আইটেমগুলো পাশাপাশি রাখার জন্য এবং নির্দিষ্ট সাইজ দেওয়ার জন্য inline-block ব্যবহার করা হয়।৪. display: noneব্যাখ্যা: এটি এলিমেন্টটিকে ওয়েবসাইট থেকে পুরোপুরি লুকিয়ে ফেলে। এটি পেজের লেআউট থেকেও উঠে যায় (কোনো খালি জায়গাও রাখে না)।CSS.secret-box {
  display: none;
}
ব্যাখ্যা: ড্রপডাউন মেনু বা মোডাল বন্ধ রাখার মতো ডাইনামিক কাজের ক্ষেত্রেJavaScript দিয়ে এটি হাইড বা শো করা হয়।৫. display: flexব্যাখ্যা: এটি ১D (একমাত্রিক) লেআউট তৈরির আধুনিক পদ্ধতি। এলিমেন্টগুলোকে খুব সহজে সারি (row) বা কলাম (column) আকারে সাজানো ও এলাইন করা যায়।HTML<div class="container">
  <div>১</div>
  <div>২</div>
</div>
CSS.container {
  display: flex;
  justify-content: space-between;
}
ব্যাখ্যা: প্যারেন্ট এলিমেন্টে display: flex দিলে চাইল্ড এলিমেন্টগুলো স্বয়ংক্রিয়ভাবে পাশাপাশি চলে আসে এবং justify-content দিয়ে ফাঁকা জায়গা অ্যাডজাস্ট করা যায়।৬. display: gridব্যাখ্যা: এটি ২D (দ্বিমাত্রিক) লেআউট সিস্টেম। এতে একই সাথে সারি (Rows) এবং কলাম (Columns) নিয়ে জটিল ওয়েব লেআউট তৈরি করা যায়।CSS.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}
ব্যাখ্যা: এখানে ৩টি সমান আকারের কলামের একটি গ্রিড তৈরি হবে, যা ইমেজ গ্যালারি বা কার্ড লেআউটের জন্য অত্যন্ত উপযোগী।

display প্রপার্টিকে একদম সহজ বাস্তব জীবনের উদাহরণ দিয়ে উপস্থাপন করা হলো:Valueসহজ বাস্তব উদাহরণমূল আচরণblockইট বা বড় বাক্সসবসময় নতুন লাইনে বসে এবং পুরো প্রস্থ দখল করে।inlineবাক্যের ভেতরের শব্দএকই লাইনে পাশাপাশি বসে, কিন্তু নির্দিষ্ট সাইজ দেওয়া যায় না।inline-blockপাশাপাশি রাখা ছবি বা বাটনএকই লাইনে থাকে, আবার ইচ্ছামতো সাইজও দেওয়া যায়।noneগায়েবি চাদরওয়েবসাইট থেকে পুরোপুরি অদৃশ্য হয়ে যায়।flexইলাস্টিক ব্যান্ড (১D)ভেতরের সব উপাদানকে এক সারিতে সহজে সাজায়।gridসুডোকু ঘর বা টেবিল (২D)সারি এবং কলাম ধরে বক্স আকারে পেজ সাজায়।১. block (বড় বাক্সের মতো)বাস্তব উদাহরণ: একটি নতুন ইট বসালে যেমন পুরো একটা জায়গা নিয়ে নেয় এবং পরের ইট নিচে রাখতে হয়।কোড উদাহরণ:CSSh1 {
  display: block;
  background-color: yellow;
}
আচরণ: লেখা ছোট হলেও পুরো লাইনের জায়গা দখল করবে এবং পরের এলিমেন্টটি নিচে চলে যাবে।২. inline (লাইনের ভেতরের অক্ষরের মতো)বাস্তব উদাহরণ: একটা খাতার লাইনে একটার পর একটা শব্দ লেখা।কোড উদাহরণ:CSSspan {
  display: inline;
  width: 200px; /* এটি কাজ করবে না */
}
আচরণ: টেক্সটের মাঝে নির্দিষ্ট অংশ কালার করতে ব্যবহার হয়। এতে নির্দিষ্ট width বা height সেট করলে তা কাজ করে না।৩. inline-block (উভয়ের হাইব্রিড)বাস্তব উদাহরণ: পাশাপাশি সাজানো ছোট ছোট গিফট বক্স।কোড উদাহরণ:CSS.card {
  display: inline-block;
  width: 150px;
  height: 100px;
}
আচরণ: এলিমেন্টগুলো একই লাইনে পাশাপাশি থাকবে, আবার এদের নির্দিষ্ট দৈর্ঘ্য ও প্রস্থও কাজ করবে।৪. display: none (পুরোপুরি উধাও)বাস্তব উদাহরণ: কোনো জিনিসকে ঘর থেকে একদম বাইরে সরিয়ে ফেলা।কোড উদাহরণ:CSS.popup-box {
  display: none;
}
আচরণ: এলিমেন্টটি স্ক্রিনে থাকবেই না এবং অন্য এলিমেন্ট তার খালি জায়গাটি পূরণ করে নেবে।৫. flex (লাইন সাজানোর জাদুকরী ম্যাজিক)বাস্তব উদাহরণ: একটি বাসের সিট যেখানে যাত্রী বাড়লে বা কমলে সিটগুলো নিজেকে অ্যাডজাস্ট করে নেয়।কোড উদাহরণ:CSS.navbar {
  display: flex;
  justify-content: space-around;
}
আচরণ: প্যারেন্ট ট্যাগে flex দিলে চাইল্ড আইটেমগুলো অটোমেটিক পাশাপাশি চমৎকার দূরত্ব রেখে সাজিয়ে যায়।৬. grid (ছক বা টেবিল)বাস্তব উদাহরণ: দাবা বোর্ড বা খাতার ছককাটা ঘর।কোড উদাহরণ:CSS.photo-gallery {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* ৩টি সমান কলাম */
}
আচরণ: রোর পাশাপাশি কলাম ধরে খুব সুন্দর প্রোডাক্ট লিস্ট বা ফটো গ্যালারি বানানো যায়।

display: contents হলো CSS-এর এমন একটি চমৎকার প্রপার্টি, যা কোনো HTML এলিমেন্টকে পেজের লেআউট বা ডোম ট্রি (DOM tree) থেকে ভিজ্যুয়ালি একধরনের 
"অদৃশ্য বা গায়েব" করে দেয়, কিন্তু তার ভিতরের চাইল্ড (child) এলিমেন্টগুলোকে টিকিয়ে রাখে।সহজ ভাষায় বললে,
 display: contents ব্যবহার করলে ব্রাউজার মনে করে সেই নির্দিষ্ট প্যারেন্ট (Parent) এলিমেন্টটির নিজের কোনো অস্তিত্বই নেই।
 ফলে তার চাইল্ড এলিমেন্টগুলো সরাসরি গ্র্যান্ডপ্যারেন্ট (Grandparent)-এর চাইল্ড হিসেবে আচরণ করা শুরু করে।সহজ বাস্তব উদাহরণ
:একটি গিফট বক্সের ভেতরে কিছু চকলেট আছে। আপনি যদি display: contents ব্যবহার করেন, তবে গিফট বক্স বা মোড়কটি অদৃশ্য হয়ে যাবে,
 কিন্তু চকলেটগুলো যেভাবে ছিল সেভাবেই মেঝেতে থাকবে।এটি যেভাবে কাজ করেধরা যাক,
 একটি Flexbox বা Grid লেআউট তৈরি করছেন:HTML:HTML<div class="container">
  <div class="box-wrapper">
    <div class="box">১</div>
    <div class="box">২</div>
  </div>
</div>
CSS:CSS.container {
  display: flex; /* কেবল সরাসরি চাইল্ডের ওপর কাজ করে */
}

.box-wrapper {
  display: contents; /* এই ডিভটির ভিজ্যুয়াল অস্তিত্ব মুছে যাবে */
}
কী ঘটবে?সাধারণ নিয়মে .container-এর সরাসরি চাইল্ড হওয়ার কথা ছিল .box-wrapper।কিন্তু .
box-wrapper-এ display: contents দেওয়ার ফলে ব্রাউজার এটিকে সম্পূর্ণ লেআউট ট্রি থেকে সরিয়ে দেয়।এখন
 .box (১ এবং ২) এলিমেন্ট দুটি সরাসরি .container-এর Flex item হিসেবে কাজ করবে।কী কী গায়েব হয় আর কী থেকে যায়?গায়েব হয়ে যায়:
এলিমেন্টটির background-color, border, padding, margin, width, height ইত্যাদি স্টাইল আর কাজ করবে না।
থেকে যায়:চাইল্ড এলিমেন্টসমূহ: চাইল্ড এলিমেন্টগুলো স্বাভাবিকভাবেই স্ক্রিনে রেন্ডার হবে।ইনহেরিটেন্স (Inheritance): 
প্যারেন্ট এলিমেন্টে ফন্ট বা কালারের মতো কোনো ইনহেরিটেড প্রপার্টি দেওয়া থাকলে (color: red, font-family),
 তা চাইল্ড এলিমেন্টে ঠিকই কাজ করবে।ইভেন্ট ও অ্যাক্সেসিবিলিটি: জাভাস্ক্রিপ্ট ইভেন্ট (যেমন click) বা HTML এট্রিবিউট বজায় থাকে।এটি কেন এবং কখন ব্যবহার করবেন?
১. Grid বা Flexbox লেআউটের জটিলতা দূর করতে:অনেক সময় সেমান্টিক (Semantic) বা স্ট্রাকচারাল কারণে HTML-এ অতিরিক্ত <div> বা <wrapper> ট্যাগ নিতে হয়।
 কিন্তু সেই অতিরিক্ত ট্যাগের কারণে Flexbox বা Grid লেআউট ভেঙে যেতে পারে। তখন display: contents ব্যবহার করে সেই র‍্যাপার ট্যাগটিকে লেআউটের বাইরে রাখা যায়।
২. Semantic HTML বজায় রাখতে:যেমন একটি <ul> বা <ol> এর ভেতরে লিস্ট তৈরি না করে মাঝখানে কোনো সেমান্টিক ডিভ বা র‍্যাপার লাগলে,
 সেই ডিভটিতে display: contents দিলে লিস্টের ডিফল্ট আচরণ নষ্ট হয় না।একটি গুরুত্বপূর্ণ সীমাবদ্ধতা (Caveat)অতীতের কিছু পুরনো ব্রাউজারে
 display: contents দিলে স্ক্রিন রিডার (Accessibility tools) ওই এলিমেন্ট এবং তার ভিতরের এলিমেন্টকে ঠিকমতো পড়তে পারত না। 
যদিও আধুনিক সব ব্রাউজারে (Chrome, Firefox, Safari) এটি সমাধান হয়ে গেছে, তবুও অ্যাক্সেসিবিলিটির দিকটি বিবেচনায় রাখা ভালো।
