CSS Flexbox (Flexible Box Layout) ওয়েব পেজে উপাদানগুলো (elements) সহজে সাজাতে এবং রেসপনসিভ ডিজাইন তৈরি করতে ব্যবহৃত হয়।

Flexbox-এ দুই ধরনের প্রপার্টি থাকে:

Parent Container (Flex Container) Properties – যা মেইন কন্টেইনারের ওপর কাজ করে।

Child Items (Flex Items) Properties – যা কন্টেইনারের ভিতরের উপাদানগুলোর ওপর কাজ করে।
Parent Container Properties (ফ্লেক্স কন্টেইনারের প্রপার্টি)
একটি HTML element-কে Flex container করতে প্রথমে display: flex; ব্যবহার করতে হয়।

CSS
.container {
  display: flex; /* অথবা inline-flex */
}
১. flex-direction
ফ্লেক্স আইটেমগুলো কোন দিকে সাজানো হবে তা নির্ধারণ করে।

row (Default): বাম থেকে ডানে একটি সারিতে সাজাবে।

row-reverse: ডান থেকে বামে উল্টো সারিতে সাজাবে।

column: উপর থেকে নিচে কলাম আকারে সাজাবে।

column-reverse: নিচ থেকে উপরে উল্টো কলাম আকারে সাজাবে।

CSS
.container {
  flex-direction: row; /* row | row-reverse | column | column-reverse */
}
২. flex-wrap
কন্টেইনারের জায়গা শেষ হয়ে গেলে আইটেমগুলো নতুন লাইনে নামবে কি না তা ঠিক করে।

nowrap (Default): সব আইটেম এক লাইনেই চ্যাপ্টা হয়ে থাকবে, নতুন লাইনে যাবে না।

wrap: জায়গা না থাকলে আইটেমগুলো পরের লাইনে চলে যাবে।

wrap-reverse: নতুন লাইনে যাবে তবে নিচ থেকে উপরে সাজাবে।

CSS
.container {
  flex-wrap: wrap; /* nowrap | wrap | wrap-reverse */
}
৪. justify-content
প্রধান অক্ষ বা মেইন অ্যাক্সিস (Main Axis - সাধারণত আনুভূমিক বা horizontal) অনুযায়ী আইটেমগুলোকে এলাইন করে।

flex-start (Default): কন্টেইনারের শুরুতে গুচ্ছ করে রাখবে।

flex-end: কন্টেইনারের শেষে গুচ্ছ করে রাখবে।

center: মাঝে নিয়ে আসবে।

space-between: প্রথম আইটেম শুরুতে, শেষ আইটেম শেষে রেখে মাঝখানের আইটেমগুলোতে সমান ফাঁকা জায়গা দেবে।

space-around: প্রতিটি আইটেমের চারপাশে সমান ফাঁকা জায়গা রাখবে।

space-evenly: প্রতিটি আইটেম এবং কিনারের মাঝের ফাঁকা জায়গা একেবারে সমান করবে।

CSS
.container {
  justify-content: center; /* flex-start | flex-end | center | space-between | space-around | space-evenly */
}
৫. align-items
ক্রস অ্যাক্সিস (Cross Axis - সাধারণত উল্লম্ব বা vertical) অনুযায়ী আইটেমগুলোকে এলাইন করে।

stretch (Default): কন্টেইনারের পুরো উচ্চতা জুড়ে প্রসারিত হবে।

flex-start: কন্টেইনারের উপরে থাকবে।

flex-end: কন্টেইনারের নিচে থাকবে।

center: উল্লম্বভাবে একদম মাঝে থাকবে।

baseline: আইটেমের ভেতরের টেক্সটের বেসলাইন অনুযায়ী সাজাবে।

CSS
.container {
  align-items: center; /* stretch | flex-start | flex-end | center | baseline */
}
৬. align-content
flex-wrap: wrap ব্যবহার করা হলে বহুমাত্রিক লাইনগুলোর (multiple lines) মাঝের খালি জায়গা কীভাবে সাজানো হবে তা নিয়ন্ত্রণ করে।

stretch (Default): লাইনগুলো খালি জায়গা পূরণ করতে প্রসারিত হয়।

flex-start: সব লাইন উপরে একসাথে থাকবে।

flex-end: সব লাইন নিচে একসাথে থাকবে।

center: সব লাইন মাঝে একসাথে থাকবে।

space-between: লাইনগুলোর মাঝে সমান দূরত্ব থাকবে।

space-around: প্রতিটি লাইনের চারপাশে সমান জায়গা থাকবে।

CSS
.container {
  align-content: space-between; /* stretch | flex-start | flex-end | center | space-between | space-around */
}
২. flex-grow
কন্টেইনারে অতিরিক্ত জায়গা থাকলে একটি আইটেম অন্যান্য আইটেমের তুলনায় কতটা বড় হবে (বৃদ্ধি পাবে) তা নির্ধারণ করে। ডিফল্ট ভ্যালু 0 (বাড়বে না)।

CSS
.item {
  flex-grow: 1; /* সব আইটেম সমানভাবে বড় হয়ে খালি জায়গা পূরণ করবে */
}
.special-item {
  flex-grow: 2; /* অন্য আইটেমের চেয়ে দ্বিগুণ জায়গায় বড় হবে */
}
৩. flex-shrink
কন্টেইনারের জায়গা ছোট হয়ে গেলে আইটেমটি অন্যান্য আইটেমের তুলনায় কতটা সংকুচিত (ছোট) হবে তা নির্ধারণ করে। ডিফল্ট ভ্যালু 1 (প্রয়োজনে ছোট হবে)। 0 দিলে সংকুচিত হবে না।

CSS
.item {
  flex-shrink: 0; /* জায়গা কম থাকলেও এটি ছোট হবে না */
}
৬. align-self
কন্টেইনারের align-items প্রপার্টিকে ওভাররাইড করে একটি নির্দিষ্ট ফ্লেক্স আইটেমের জন্য আলাদা Alignment সেট করে।

CSS
.item {
  align-self: flex-end; /* কন্টেইনারের align-items যাই থাকুক, এই আইটেমটি নিচে থাকবে */
}
HTML
<div class="flex-container">
  <div class="card">Card 1</div>
  <div class="card special">Card 2</div>
  <div class="card">Card 3</div>
</div>
CSS Code:

CSS
/* Container Setup */
.flex-container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  gap: 15px;
  background-color: #f1f1f1;
  padding: 20px;
}

/* Individual Item Setup */
.card {
  background-color: #4CAF50;
  color: white;
  padding: 20px;
  flex-grow: 1; /* সব কার্ড সমান ফাঁকা জায়গা দখল করবে */
  text-align: center;
}

.card.special {
