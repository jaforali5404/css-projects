CSS-এ position প্রপার্টি দিয়ে একটি HTML এলিমেন্ট ওয়েবপেজে কোথায় এবং কীভাবে দেখাবে তা নির্ধারণ করা হয়।position প্রপার্টির মোট ৫টি মূল ভ্যালু (Value) রয়েছে:
static (ডিফল্ট ভ্যালু)
relative
absolute
fixeds
tickyএই ভ্যালুগুলোর সাথে এলিমেন্টের অবস্থান নির্ধারণের জন্য ৪টি পজিশনিং প্রপার্টি (Offset Properties) এবং ১টি স্ট্যাকিং প্রপার্টি ব্যবহার করা হয়:top, bottom, left, right (পিক্সেল, পার্সেন্টেজ ইত্যাদিতে মান দেওয়া হয়)z-index (কোন এলিমেন্ট উপরে বা নিচে থাকবে তা ঠিক করতে)১. static (ডিফল্ট)এটি সাধারণ নরমাল ফ্লো (Normal Flow)। এইচটিএমএল কোড যেভাবে লেখা হয়, এলিমেন্টগুলো সেভাবেই পর পর অবস্থান করে।বৈশিষ্ট্য: top, bottom, left, right বা z-index কাজ করে না।CSS.box {
  position: static;
}
২. relativeএলিমেন্টটি তার নিজস্ব আসল অবস্থান (Original Position) থেকে কতটুকু সরবে তা নির্ধারণ করে।বৈশিষ্ট্য: এটি নরমাল ফ্লোতেই থাকে, তবে top/left দিলে নিজের জায়গা থেকে সরে যায়। অন্য এলিমেন্টগুলো মনে করে এটি আগের জায়গাতেই আছে।HTML<div class="relative-box">আমি সরবো</div>
CSS.relative-box {
  position: relative;
  top: 20px;   /* আসল জায়গা থেকে ২০ পিক্সেল নিচে নামবে */
  left: 30px;  /* আসল জায়গা থেকে ৩০ পিক্সেল ডানে সরবে */
}
৩. absoluteএলিমেন্টটি নরমাল ফ্লো থেকে একদম বের হয়ে যায় এবং তার নিকটতম প্যারেন্ট এলিমেন্ট (যার position relative, absolute বা fixed করা আছে) তার সাপেক্ষে অবস্থান নেয়।বৈশিষ্ট্য: প্যারেন্টে কোনো পজিশন দেওয়া না থাকলে এটি পুরো বডি/ভিউপোর্ট (<body>) সাপেক্ষে সরবে।HTML<div class="parent">
  <div class="child">আমি প্যারেন্টের সাথে পজিশন হবো</div>
</div>
CSS.parent {
  position: relative; /* প্যারেন্টকে রিলেটিভ রাখা জরুরি */
  width: 300px;
  height: 200px;
}

.child {
  position: absolute;
  top: 0;
  right: 0; /* প্যারেন্টের একদম উপরে-ডান কোণায় বসে যাবে */
}
৪. fixedস্ক্রিন বা ভিউপোর্ট (Viewport)-এর সাপেক্ষে এলিমেন্টের জায়গা নির্দিষ্ট করে দেয়।বৈশিষ্ট্য: পেজ স্ক্রোল করলেও এই এলিমেন্টটি তার জায়গায় স্থির থাকে। নেভিগেশন বার বা "Back to Top" বাটনে এটি ব্যবহার হয়।CSS.fixed-btn {
  position: fixed;
  bottom: 20px;
  right: 20px; /* পেজ স্ক্রোল করলেও স্ক্রিনের নিচে-ডানে জমে থাকবে */
}
৫. stickyএটি relative এবং fixed-এর একটি চমৎকার মিশ্রণ।বৈশিষ্ট্য: এটি প্রথমে সাধারণ এলিমেন্টের মতো কাজ করে, কিন্তু স্ক্রোল করতে করতে যখন নির্দিষ্ট সীমানায় (top বা bottom) পৌঁছায়, তখন এটি fixed হয়ে আটকে থাকে।CSS.navbar {
  position: sticky;
  top: 0; /* স্ক্রোল করে উপরে পৌঁছালেই আটকে যাবে */
}
